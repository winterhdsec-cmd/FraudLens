## 4. 技术路线

### 4.1 后端架构

```
FastAPI（主入口）
  ├── agents/          # 多智能体（orchestrator/analyst/cluster/chat/reflect）
  ├── gnn/             # 图神经网络（han_model/gnn_model/graph_builder/gang_detector）
  ├── core/            # 核心模块（config/security/checkpoint/circuit_breaker/llm_client）
  ├── database/        # 数据层（models/connection/seed/es_store）
  ├── routes/          # API 路由（26 端点）
  ├── schemas/         # Pydantic 模型
  ├── tools/           # 工具集（ocr/vision/database/evidence/risk/mask）
  ├── memory/          # 记忆系统（short/long/vector）
  └── rag/             # 知识检索（knowledge_base/reranker/semantic_chunking）

Celery Worker          # 异步任务（研判）
```

### 4.2 前端架构

```
Vue3 + Vite + Element Plus
  ├── router/          # 路由
  ├── views/           # 19 个页面视图
  ├── components/      # NetworkGraph/MiniNetworkGraph/ShowcaseView
  ├── composables/     # useFraudLens/useAppState
  ├── store.js         # 状态管理
  └── api.js           # API 封装
```

### 4.3 算法流水线

```
输入: 案件材料（文本/CSV/DOCX）
  → 预处理: 实体抽取（正则 + LLM）+ 资金流解析
  → 异构图构建: 5 类节点 + 5 条元路径
  → HAN 表征学习: GraphCL 预训练 → 语义注意力融合
  → 社区发现: KMeans/Louvain（可切换）
  → 置信度门控: 4 因子加权 → gate_decision
  → 资金回流检测: nx.simple_cycles
输出: 团伙划分 + 可冻卡清单 + 研判报告
```

## 6. 风险与应对

| 风险 | 影响 | 概率 | 应对 |
|------|------|------|------|
| 论文A 截稿延期 | CPEC 错过 | 中 | 当前 85%，待办均为填信息，可控 |
