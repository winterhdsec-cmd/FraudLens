## 投稿注意事项

### 通用规则

1. **一篇一投**：同一篇论文不同时投多个期刊
2. **先投A再投B**：论文A（CPEC）和论文B（技术）虽内容不同，但建议A有结果后再投B
3. **专利先行**：若后续要申请专利，论文B发表前先确认专利优先权日
4. **基金标注**：两篇均标注大创 S202611332001 + 院级科研项目

### 投稿前检查清单

- [ ] 论文查重率 < 15%（普刊通常要求）
- [ ] 格式符合期刊/会议要求
- [ ] 参考文献全部为正文引用（无虚引）
- [ ] 署名经所有作者确认
- [ ] 基金编号正确
- [ ] 通讯作者邮箱可用
- [ ] 无敏感信息泄露（API Key 等）
