> **文档编号**: TEST-PLAN-001 | **版本**: v1.0 | **日期**: 2026-08-04  
> **测试环境**: Docker Compose 全栈 | **测试框架**: pytest + unittest

---

## 1. 测试策略

### 测试金字塔

```
        ┌──────┐
        │ E2E  │  2%  — 端到端研判流程
       ┌┴──────┴┐
       │集成测试 │  20% — 模块间协作（Agent+DB/GNN+图构建/路由+鉴权）
      ┌┴────────┴┐
      │ 单元测试  │  78% — 独立函数/类（GraphBuilder/门控/HAN层/特征提取）
     └───────────┘
```

### 测试原则

1. **可复现**: 固定随机种子（`seed=42`），合成数据固定参数
2. **独立性**: 每个测试用例不依赖其他用例的执行结果
3. **诚实断言**: 不为了"通过"而放松阈值，真实算法性能是什么就是什么
4. **不编造数据**: 测试数据使用合成数据或公开数据集，不伪造"真实警务数据"
