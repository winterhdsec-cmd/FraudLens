Lpaa：基于 LangGraph 的教案自动生成智能体 
张豈明，张嘉睿，何雨晴，张琰彬  
华东师范大学数据科学与工程学院，上海  200062  
摘要：本文提出 Lpaa，一种基于 LangGraph 构建的教案自动生成智能体（ Lesson Plan 
Automatic Agent ）。该智能体由大语言模型（ Large Language Model, LLM ）驱动，通过内容
解析引擎、指令链生成器、前序步骤描述生成器、并行输出引擎与可控校准优化器等五个协
同模块， 实现知识结构提取、 教学任务分解、 阶段衔接生成、 模块并行处理与人机协同校准。
Lpaa以智能体（ agent）形式运行在 LangGraph 的图结构上，支持任务节点化、依赖约束表
达及动态调度，从而显著提升生成效率与教学内容的一致性。在自构建的多维度评估框架  
pEval 下，系统平均得分  8.48/10，得到领域专家的高度认可。消融实验进一步验证了智能
体各子模块对整体性能的关键贡献。研究表明， Lpaa为中文教案自动 生成提供了结构化、
可扩展的智能体范式，可为提升教学质量与学习体验提供有效支持。  
关键词： 课程教案生成；大语言模型（ LLM）；智能体； Lpaa；pEval

 ZHANG Qiming, ZHANG Jiarui, HE Yuqing, ZHANG Yanbin

Abstract: This paper presents Lpaa, a LangGraph -based Lesson Plan Automatic Agent designed 
for intelligent generation of Chinese lesson plans. Powered by a Large Language Model (LLM), 
the agent coordinat es five functional modules — a Content Parsing Engine, an Instruction Chain 
Generator, a Previous Step Description Generator, a Parallel Output Engine, and a Controllable 
Calibration Optimizer. These modules collaboratively support knowledge structure extra ction, 
teaching task decomposition, stepwise contextual linkage, parallel module processing, and 
human -in-the-loop calibration. Operating as an agent within the graph -structured LangGraph 
framework, Lpaa enables task node segmentation, dependency -aware sch eduling, and dynamic 
workflow management, thereby significantly improving generation efficiency and content 
consistency. Under a self -constructed multidimensional evaluation framework, pEval, the system 
achieved an average score of 8.48 out of 10 and recei ved strong recognition from domain experts.

0  引言  
课程教案是教学活动的重要组成部分， 是教师实施有效教学的基本依据。通过合理的教
案设计，教师能够明确教学目标、科学安排教学内容与时间、选择适当的教学方法与评价方
式，从而提升课堂效率与教学质量[1]。与此同时，优质教案的编写也为学生提供了清晰的学
习路径，有助于其掌握知识结构、形成系统认知，并促进深度学习与能力发展[2]。 
然而，在当前教育数字化转型的背景下，传统人工撰写教案的方式正面临效率低、资源
利用率不高等诸多挑战。一方面，教师在备课过程中需要花费大量时间整理教学内容、组织
教学环节，工作负担沉重；另一方面，不同 教师的个人经验和表达风格差异也造成了教案质
量的不均衡， 难以实现标准化与共享利用。 因此， 如何借助先进的人工智能技术， 构建高效、
规范、智能的教案生成系统，成为教育信息化领域的重要研究课题。  
近年来，随着大语言模型（ Large Language Models, LLM ）的迅猛发展，其在文本生成
方面展现出强大的能力，逐渐被应用于教案辅助生成任务中[3]。这种方法显著提升了教案生
成的速度与效率，具有广阔的应用前景。然而，已有研究和实践表明，当前基于 LLM直接
生成的教案在实际教学中存在诸多问题，例如：内容覆盖不全、深度 不够，容易遗漏关键教
学重点；教学设计缺乏系统性与阶段性，难以体现由浅入深、循序渐进的教学原则；缺乏以
学生为中心的教学视角，忽略了学生的认知特点与实际需求；教案语言呆板，缺乏教学感染
力与实用性[4]。因此，在实际教学场景中，单一依赖 LLM直接生成的教案难以真正满足教
学需求，也无法替代教师在教学设计中所体现的专业判断与教育智慧。  
针对上述问题 ，本文提出并实现了一种面向中文教案自动生成的智能代理系统  ——  
Lpaa（Lesson Plan Automatic Agent ），该系统以大语言模型为基础，结合图结构建模 、模块
化任务分解 、人机协同优化等策略 ，从“内容结构抽取 -流程构建 -上下文衔接 -并行生成 -反馈
优化 ”五个方面入手 ，力求在提升教案生成效率的同时 ，保障其教学连贯性与实际可用性 。
主要贡献如下：  
1.  本文创新性地构建一个由五大核心模块组成的智能教案生成系统 Lpaa， 包括内容解
析引擎、教学链生成器、前序步骤描述生成器、并行输出引擎以及可控校准优化器。通过模
块间的协同运作， Lpaa有效应对当前教案生成过程中存在的各类问题，确保所生成教案具
有连贯性与教育价值，为课程教案的智能生成提供了全新的解决思路。  
2.  为验证系统的性能与准确性 ，本文设计了一个系统化评估框架 —— pEval，该框架
从“内容质量 ”、“连贯性 ”与“教育价值 ”三个维度对生成结果进行全面评估[5]。实验结果表明 ，
Lpaa在pEval评估框架下表现优异，课程教案平均得分高达 8.48分（满分 10分），并获得
了多位学科专家的一致好评。这一高分评价充分体现了 Lpaa在课程教案生成领域的显著优
势与广阔应用前景。  
1 相关工作  
随着人工智能技术的不断发展，尤其是大语言模型（ Large Language Model, LLM ）在自
然语言处理领域的广泛应用， 基于智能代理的 教学辅助工具逐渐成为教育信息化的重要研究
方向[6]。其中，教案作为教学准备的核心环节，已成为诸多研究者尝试引入智能化生成机制
的重点目标。  
1.1 教案生成的传统方法与自动化探索  
长期以来 ，教案的设计主要依赖教师个人的经验积累与教学实践 。这种 “手工撰写 +经验
导向 ”的方式虽然具有一定灵活性与个性化优势 ，但存在效率低 、标准不统一 、质量参差不
齐等问题。在教育资源共享和教学质量监控日益重要的今天，这一问题尤为突出。  
为解决这一困境，近年来出现了一些利用人工智能手段辅助教案编写的研究与产品探索。早
期系统如 MagicSc hool[7]平台， 通过简单关键词提示生成基础教案大纲； 后续如 SchoolAI[8]、
Curipod[9]等工具则引入检索增强机制和多模态设计理念，尝试结合教学目标、课标知识点
与教具资源，提升生成结果的教学相关性与完整性。  
尽管这类工具在生成效率上取得了一定进展，但生成内容普遍存在以下问题：内容覆盖
不全：重要知识点缺失，教学目标泛化；结构逻辑薄弱：教学环节之间缺乏递进与呼应；缺
乏教育理论支撑：很难体现启发式教学、以学定教等现代教学理念；泛化模板化严重：尤其
在学科交叉或复杂情境中，难以适配多样教学需求[10]。这些问题表明，当前主流方法多停
留在 “文本填空式 ”的自动生成阶段 ，缺乏对教学任务流程的深入建模与多层次内容理解 ，限
制了自动教案系统的实用价值。  
 
1.2 LLM 作为教学智能体的角色  
为了更好地发挥 LLM的潜力，一些研究者开始尝试将其视作 “智能体 ”（Intelligent Agent ）
使用，即不再将 LLM仅作为生成工具，而是作为能感知上下文、推理任务逻辑并执行多阶
段教学规划的 “教学搭档 ”[11]。 
这一思路下 ，LLM可模拟 “教师 ”角色，具备以下能力 ：结合课程内容 、教学目标与学
情分析，实现定制化教学活动设计；引 入记忆机制[12]与教学进度追踪，实现动态调整的教
学任务链；针对不同学习者特征，生成更具个性化的教学内容与互动设计。在此背景下，具
备图结构建模能力的 LangGraph 框架被引入教案生成流程中[13]。其通过图神经结构组织任
务节点，支持多个教学环节并行生成与跨步骤信息流转，大幅提升了教学设计的结构完整性
与执行效率。例如，针对多个知识点并行展开讲解、活动设计与评价安排， LangGraph 都能
提供高效有序的生成路径。  
1.3 LLM 在教案质量评价中的作用  
除生成端探索外， LLM也被用于教案质量的自动评估任务[14]。近年来，研究者提出了
包括 Auto -Arena[15]、G-Eval[16]等在内的一系列智能评价框架，通过多模型协同讨论、评审
投票等方式，对生成教案的完整性、逻辑性、创新性等维度进行评估，从而降低人工评审成
本并提升客观性。  
具体到教案场景中， LLM作为评价工具能够：识别教学目标与课时内容是否匹配；分
析教学逻辑是否清晰、过渡是否自然；评价语言表达是否规范、是否具启发性；针对不同学
段和学科，判断教学策略是否合理。这些研究表明， LLM不仅在教案生成方面具有广阔应
用空间，在教案评价与优化环节同样展现出强大 潜力。  
2 Lpaa  
为解决现有教案自动生成系统中存在的效率低、结构不清、内容缺乏教学逻辑的问题，
本文提出  Lpaa ——  一个基于大语言模型和图结构驱动的模块化中文教案生成系统 。Lpaa 
从教案生成任务的本质出发 ，将其拆解为 “内容结构识别 —教学链路构建 —步骤衔接说明 —
并行内容生成 —反馈驱动优化 ”五个阶段 ，通过五大核心模块协同工作 ，最终实现高效 、可
控、富有教育价值的教案自动构建。

2.5 可控校准优化器  
自动生成的教案往往需要根据教学场景、教师偏好或学段特征进行调整。若缺少人机协
同的微调机制， 系统生成的内容难以满足实际教学需求。 可控校准优化器通过引入可控参数、
人机交互式反馈以及局部重写机制，使系统具备可解释性与可修正性，增强了教案的可用性
与落地性。在课程提纲初步生成完成后，可控校准优 化器提供人机交互功能，使用户能够基
于反馈意见实时调整课程提纲内容。该模块可快速响应用户的修改建议，优化课程提纲的准
确性与实用性，确保生成的课程提纲更契合教学需求与教育原则。  
系统提供界面或  API，供用户（如教师或教育专家）对课程提纲内容进行评估与反馈。
用户可以指出课程提纲中的错误、遗漏或改进空间，并提出具体的修改建议。可控校准优化
器接收用户反馈，并基于该信息实时调整课程提纲内容。该调整过程可表示为：

本模块的设计理念参考了已有研究中关于 “人机协同校准 ”和“可控生成 ”的通用框架[26]，
但并非直接复用某一具体方法，而是结合教案生成的任务特征进行了工程化适配与扩展，从

通过可控校准优化器， Lpaa不仅在初次生成阶段能够保证课程提纲的整体质量，还能

系统的实用性与可落地性。

3.2 实验细节  
我们选取了以下基线方法进行对比：  
常规方法（ Common Method ）：直接使用 MagicSchool 平台生成课程教案。该方法代表了
当前业界常用的自动化教案生成方式。  
专业方法（ Professional Method ）：利用  GPT -o3 [28]生成课程教案，随后由华东师范大学的
学科专家进行人工修订。该方法融合了先进的人工智能技术与专业教育者的经验，代表了当
前领域的最新研究水平。  
Lpaa的实现基于两个模型： Qwen2.5 -14B-Instruct与Qwen2.5 -72B-Instruct[29]。每次生成
过程中，系统的输入包括学科、年级、课时数以及章节信息，随后由 Lpaa框架自动生成教
案。该设计旨在评估不同模型在生成高质量教案方面的表现。  
3.3 评估指标  
PPL（困惑度）： 使用 Qwen2.5 -32B模型计算课程教案的平均困惑度。较低的困惑度得
分表示文本流畅度更高[30]。 
Rouge -L：一种基于最长公共子序列（ LCS）的评估指标，用于衡量生成文本与参考文
本之间的相似度 。在本研究中 ，我们将 “专业方法 ”作为参考文本[31]。 
Coverage （覆盖度） ：评估生成的课程教案中涵盖了多少关键主题和教学目标。该指
标通过检查教案是否包括预定义的关键知识点和教学目标，来衡量内容的全面性。  
CLI（认知负荷指数）： 认知负荷指数是一种衡量教学材料对学生认知负担的指标。它
通过分析课程教案的语言复杂性、信息密度和结构清晰度，评估学生在学习过程中可能面临
的认知压力。较低的 CLI值表明教案更易于理解和学习，有助于减轻学生的学习负担[32]。 
pEval：我们引入的综合评估框架，使用 GPT -o3作为评估模型，从内容、连贯性和教
育价值三个维度评估教案的质量，如表 2所示。该框架填补了教案生成领域缺乏无参考评估
的空白。 pEval 框架提供 0到10的数值评分，并为每个维度的评估结果提供详细的评判理
由。 pEval 的详细信息和实现可以参见 附录。 
表2  pEval 评估框架中的评估维度与评分标准

5 总结  
本文提出了一种面向中文教案自动生成任务的智能系统  ——  Lpaa（Lesson Plan 
Automatic Agent ）。该系统融合大语言模型生成能力与模块化结构设计，围绕内容解析、指
令链生成、操作描述优化、并行输出和可控校准优化五个核心步骤，构建出高效、可控、富
有教育价值的教案自动生成流程。  
为验证系统效果，本文构建了教案数据集  PK12，涵盖语文与数学等典型学科，并设计
了多维度评估指标体系  pEval，从语言流畅性、教学覆盖度、认知负荷、教学逻辑及教育价
值等方面全面评估系统性能。实验结果表明， Lpaa 在内容质量、教学逻辑性与教育适配度
方面均显著优于传统模板化或直接生成方法，接近专业教师撰写教案水平。同时，通过模块
消融实验与人工评分一致性分析，进一步验证了系统设计的合理性与评估方法的有效性。  
尽管本研究取得了积极成果，但仍存在一些局限性，值得在后续工作中进一步优化：多
样化学科适配性有待拓展：当前系统主要在语文与数学场景中实验验证，尚未广泛 适配跨学
科项目式教学等复杂类型。多模态生成能力尚不完备：目前系统侧重于文本教案生成，尚未
集成如教学板书图示、流程图、实验视频等多模态教辅要素，限制了系统的课堂实用性与互
动性。个性化与区域性教学场景适应仍有挑战：不同地区、学校及教师对教案风格与课程资
源的偏好不同 ，如何引入个性化画像机制 ，实现真正 “因人施教 ”的教案定制 ，是下一步研究
重点。  
未来，我们将从以下方向展开工作：拓展教案生成模型的学科覆盖范围，引入更多年级
段与课程类型；探索图文多模态教案生成机制，增强可视化输出能力；引入教师知识图谱与
教学风格建模， 实现 个性化教案推荐； 推动系统在教学一线的真实应用测试， 采集反馈数据，
持续优化生成质量。  
综上所述， Lpaa 在中文教案自动生成任务中表现出良好的应用潜力。通过模块化系统
设计与多维度评估实验，我们验证了各模块在提升内容质量、教学逻辑性与适用性方面的作
用。然而，该系统仍有待在更多学科场景、多模态内容以及个性化教学需求下进一步验证和
完善。未来的研究将重点关注扩展学科覆盖、增强多模态输出能力、引入个性化建模机制，
并在真实教学场景中持续收集反馈，以推进系统的实际应用价值与稳定性评估。

pEval 框架的详细说明  
pEval 是一个专为评估课程提纲质量而设计的综合性评估框架。它利用  GPT -3 作为评
估模型，能够对生成的课程提纲进行多维度分析 。该框架解决了课程提纲生成领域缺乏 “无
参照式 ”评估方法的关键问题 ，从而提供了一种更为客观和全面的评估手段 。 
pEval 的评估维度与评分标准  
pEval 从内容性、连贯性和教育价值三个关键维度对课程提纲进行评估。每个维度都基
于特定标准进行评分，确保对课程提纲的质量进行深入细致的评价。框架为每个维度打分的
范围为  0 到 10 分，并提供详细的评分理由，以解释评估结果。这种评分机制不仅量化了
课程提纲的质量，也提供了定性见解，揭示其优点与不足。  
内容  
评分标准 ：该维度评估课程提纲是否全面深入，语言是否清晰简洁。具体包括提纲是否覆盖
必要的知识点与学习目标，信息是否详尽且便于理解。  
评分理由 ：高分说明该课程提纲在内容呈现上条理清晰、组织良好，有助于教学目标的实现
和学生的有效学习。  
连贯性  
评分标准 ：该维度关注课程提纲的逻辑结构，重点考察内容是否按逻辑递进、是否符合学生
发展规律。它评估提纲内容的清晰性与逻辑流畅性，确保各部分内容层层递进，结构系统。  
评分理由 ：高分说明课程提纲结构清晰、逻辑合理，有助于吸引学生注意力并促进其持续学
习。  
教育价值  
评分标准 ：该维度评估课程提纲是否以学生为中心，教学内容是否由浅入深、符合学生的认
知发展规律。同时，它还关注理论知识与实际生活的结合程度，确保课程既提供学术知识，
也提升学生的实践能力与现实理解。  
评分理由 ：高分说明该课程提纲充分考虑了学生的学习需求与认知特点，有助于促进学生的
全面发展，并为其应对现实挑战做好准备。  
pEval 的意义  
pEval 框架在课程提纲评估领域具有重要意义。通过提供一种多维度、无参照的评估方
法，它相较于传统方法更加全面且客观。详尽的评分标准和评估理由，使教育者与开发者能
够深入理解课程提纲的优劣势，推动持续改进与优化。  
总而言之， pEval 是一个强大而灵活的评估工具，能够提升课程提纲生成的质量与效果。其
多维评估方法与细致的评价标准，使其成为教育技术与课程设计领域研究者、教育工作者和
开发人员的重要参考资源。
