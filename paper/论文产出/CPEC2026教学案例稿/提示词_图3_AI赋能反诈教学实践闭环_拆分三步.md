## 统一风格规范（必须符合）

- **配色**：仅 黑 `#333333`、白 `#FFFFFF`、浅灰（背景岛 `#F5F5F5` / 标题栏 `#E8E8E8`）。禁止彩色、渐变、阴影。
- **字体**：中文 `Microsoft YaHei`（或 `SimHei`），英文数字 `Arial`；大岛标题 13pt 加粗，子模块 8–9pt 常规。
- **形状**：模块一律**直角矩形**（`rounded=0`），黑边 `strokeWidth=1.5`；大岛浅灰背景，岛内子模块白色。
- **箭头**：`endArrow=block`，颜色 `#333333`；**实线=主流程/协同**，**虚线=反馈/边界**。**菱形只放判断，矩形只放动作**。
- **图标**：不用厂商 logo，用文字。
- **层次**：用浅灰大岛把"一组相关模块"圈成视觉岛；**中央实训闭环为最大内核**，输入在左、增强在上、输出在右、反馈回环到底部。
- **文字**：简体中文，不溢出框。

## 第 2 步 · 填充内部子模块（白色直角节点，不改位置）

（在骨架上继续）给各模块填充白色直角子模块（`rounded=0`，白底黑边 `1.5`）：

1. **左侧输入岛**（竖向 2 个）：
   - 学生（准民警）
   - 教师（配置任务 / 获取学情）

2. **上方增强岛 · FraudLens 智能助教**（2×2 白色子模块）：
   - 规划 Agent
   - BGE 嵌入 Agent
   - GNN 聚类 Agent
   - 反思 Agent

3. **中央闭环各 Lab 内部子模块**：
   - Lab1 情境导入：真实案情库 / 合成数据（AMLSim 1,305 环）/ 案件背景卡片
   - Lab2 工具辅助串并案：规则引擎 / BGE 语义嵌入 / HAN 异构图 / GraphSAGE 资金链
   - Lab3 冻卡决策与伦理权衡：候选结果 / 规则 vs AI 对比 / 冻卡决策（可在内部加白色菱形「是否冻卡？」）
   - Lab4 边界认知与诚实反思：失败案例（AMLSim 全图 F1≈0.002）/ AI 非全设定占优 / 诚实口径
   - 评价回流：加权评价量表 + 思政 / 伦理映射

4. **右侧输出岛 · 育人目标**（竖向 3 个）：
   - 算法边界认知
   - 伦理决策素养
   - 课程思政（科技向善）

5. **右下边界岛**：
   - `AI 可辅助`：嵌入检索 · 聚类归集 · 生成候选 · 规则对比 · 过程性评价
   - `AI 不可靠 / 须教师把关`：全图判定 · 因果定责 · 最终执法决策 · 伦理责任归属

6. **底条**：写「评价 → 再学情」。

【要求】白色子模块、直角、黑细边；简体中文不溢出；小字号 8–9pt 放得下。

## 第 3 步 · 连线、菱形、反馈环、边界标注（学术 Visio 风收尾）

（在已填充图上继续）添加连接与闭环：

1. **输入 → 增强 → 内核（黑实线）**：
   - 学生 → 智能助教（标注「提问 / 获得建议」）
   - 教师 → 智能助教（标注「配置任务 / 获取学情」）
   - 智能助教 → 中央闭环的 Lab1（标注「任务 / 资源注入」）

2. **中央闭环箭头（黑实线）**：Lab1 → Lab2 → Lab3 → Lab4 → 评价回流 → 虚线返回 Lab1。

3. **Lab3 内白色菱形「是否冻卡？」**：是 → 记录处置；否 → 返回复盘（Lab4）。

4. **增强 → 内核虚线支撑**：从智能助教的「BGE 嵌入 Agent」引虚线到 Lab2；从「GNN 聚类 Agent」引虚线到 Lab2；从「反思 Agent」引虚线到 Lab4。

5. **诚实边界岛连线（虚线）**：从「AI 可辅助」引虚线连到 Lab2 / Lab3；从「AI 不可靠」引虚线连到 Lab4（边界反思）。

6. **反馈环（黑虚线）**：从「评价回流」底部 → 底部横条「评价 → 再学情」 → 绕回左侧「学生」，标注「反思 / 再学情」。

7. **输出（黑实线）**：从「评价回流」右侧引实线到「育人目标」岛，表示评价结果沉淀为学生能力成长。

8. **终检**：箭头标签不压线、文字不溢出、中央闭环层次清晰、整图仅黑白灰。
