## 图2 彻底解决：从 TikZ 手摆坐标 → Python 专用网格布局生成器
- **背景**：用户对 AI 手摆 TikZ 坐标反复出错（盒重叠/文字溢出/标签压框）失去耐心，要求换画法并联网调研。
- **调研结论**：
  - Graphviz/DOT 是通用图自动布局最强工具，但对“固定三列+背景 panel”的架构图/layout 不友好（`rankdir` 与 `cluster` 冲突，`constraint=false` 会把图摊平成关系网），试渲染后三列顺序混乱、跨栏箭头变长弧线，不可用。
  - 科研圈画这种精确分区 diagram 的终稿工具通常是 draw.io/Visio/Figma（网格对齐）或 TikZ（手写但严谨）。
- **最终方案**：**Python 专用网格布局生成器**（`build_fig_workflow.py`），平衡“自动布局不出错”与“LaTeX 矢量内联”：
  - AI 只写**图的数据与布局规则**（三列、节点文字、panel 标题、间距参数）；
  - Python 自动计算所有节点/panel/bar/箭头/标签坐标，输出完整 `fig_workflow.tex`（standalone / 可被 `_sync_figs.py` 提取 tikzpicture）；
  - XeLaTeX 编译成 PDF，保持论文字体一致；
  - 最后走 `_verify_fig.py` 量化校验“盒等高/文字在盒内/标签零重叠/图宽”。
- **关键参数**：节点等高 1.40 cm；列中心间距 3.50 cm；panel 内边距 0.40 cm；底部 audit bar 高 0.65 cm；跨栏标签 `above=18pt`（在节点上方但不碰上行节点）；反馈环折线在 panel 左侧 0.85 cm；标题分两行、左上角左对齐，避免三列标题互相覆盖。
- **量化结果**：9 盒等高 39.7 pt；3 panel + 1 bar；图宽 11.42 cm；内容文字溢出 0；浮动标签与 box/bar 重叠 0。
- **构建**：`_sync_figs.py` 同步 → 主稿 `CPEC2026_draft.tex` 增加 `arrows.meta` 库 → xelatex+bibtex×3 全 0 错误；Word 重生；备份 `CPEC2026_draft_图2彻底解决.pdf`。
- **新增/关键文件**：`build_fig_workflow.py`（可复用生成器）、`fig_workflow.tex`（自动生成）、`fig_workflow.dot`（Graphviz 探索废料，保留作记录）、`fig_workflow_gv.*`（Graphviz 渲染废料）。
