# 论文文档目录说明

> **创建日期**: 2026-08-04  
> **用途**: 说明 `docs/论文文档/` 目录应该放什么、和 `paper/` 目录的区别

---

## 两个目录的分工

FraudLens 有两处论文相关目录，**职责不同，不要混**：

| 目录 | 放什么 | 不放什么 |
|------|--------|----------|
| **`paper/`** | 论文本体（.tex / .pdf / .docx）、参考文献（.bib）、图表、编译产物、投稿材料 | 不写管理文档 |
| **`docs/论文文档/`** | 论文**管理文档**：工作计划、选题论证、文献调研、研究方法、投稿追踪 | 不放论文正文 |

---

## `docs/论文文档/` 应该建哪些文件

### 必建（建议现在就建）

| 文件名 | 内容 | 为什么需要 |
|--------|------|-----------|
| `论文工作计划.md` | 两篇论文的时间线、里程碑、当前状态、阻塞项 | 老师/队友问"论文到哪了"直接给这个 |
| `选题论证与差异化.md` | 为什么选这个题、和已有论文的区别、创新点矩阵 | 写 Related Work 和答辩时的核心素材 |
| `实验设计文档.md` | 每项实验的目的/方法/数据/预期结果/实际结果 | 论文实验章节的来源，避免"忘了哪个实验用了什么参数" |
| `投稿追踪.md` | 每篇论文投了哪里/什么时候/状态/审稿意见 | 多篇论文在投时防止混乱 |

### 建议建（视需要）

| 文件名 | 内容 | 什么时候需要 |
|--------|------|------------|
| `文献调研笔记.md` | 每篇参考论文的摘要、方法、与 FraudLens 的关系 | 写论文时需要快速回顾文献 |
| `导师反馈记录.md` | 吴燕波/徐伟老师的每次反馈 + 修改记录 | 多人协作改论文时 |
| `查重与去AI味.md` | 查重结果/去AI味策略/修改记录 | 投稿前整理 |
| `学位论文扩展计划.md` | 如果选择写成学位论文，章节扩展方案 | 从普刊升级到学位论文时 |
