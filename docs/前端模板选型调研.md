# 前端模板选型调研报告（面向 FraudLens 反诈系统）

> 调研时间：2026-08-12
> 目标：为 FraudLens（Vue3 + Element Plus，公安反诈场景，暗黑主题）选择参考模板/设计规范
> 结论先行：**不整体引入模板工程**（覆盖风险大），**提炼 vue-pure-admin 布局骨架 + 警务设计系统 token** 应用到现有项目

---

## 一、主流 Vue3 后台模板对比

| 模板 | Stars | UI 库 | 特点 | 适配度 |
|---|---|---|---|---|
| **vue-vben-admin** | ~29.6k | AntD/Naive/Element 多版 | 功能最全（权限/路由/主题），但重、学习成本高 | ★★★ 功能全但"大改"难 |
| **vue-pure-admin** | ~20k | Element Plus + Tailwind | 轻量、代码清爽、现代，二次开发友好 | ★★★★★ 最适合借鉴 |
| **vue-element-plus-admin** | ~4k | Element Plus | Element 生态开箱即用，有完整/mini 版 | ★★★★ 契合现有技术栈 |
| **Geeker-Admin** | — | Element Plus | ProTable 封装强，按钮级权限 | ★★★ 组件思路可借鉴 |
| **SoybeanAdmin** | ~8k | Naive UI | 高颜值、UnoCSS、主题丰富 | ★★★ 颜值参考 |
| **Arco Design Pro Vue** | — | Arco | 字节出品，暗黑模式完善，TS 全覆盖 | ★★★ 暗黑 token 参考 |

**选型判断**：
- FraudLens 已用 Vue3 + Element Plus，**Element Plus 生态模板**（vue-pure-admin / vue-element-plus-admin）最贴合
- **vue-pure-admin 胜出**：轻量、代码清晰（"教科书级"）、Tailwind 工具类 + 成熟的暗黑主题方案，二次开发成本最低
- vue-vben-admin 功能最全但抽象层重，适合"完整引入"不适合"局部借鉴"

## 二、公安/政务 UI 行业规范（权威依据）

### 2.1 UK Police Design System（警务系统设计规范）
专门为警务/执法场景设计的系统，**暗黑优先**（长时间分析用眼），核心原则：

**背景层级（用明度表达 elevation，不用重阴影）：**
```
--bg-canvas    hsl(220, 20%, 7%)    主背景
--bg-surface-0 hsl(220, 18%, 11%)   卡片背景
--bg-surface-1 hsl(220, 16%, 15%)   悬浮/交互层
--bg-surface-2 hsl(220, 14%, 19%)   最高层（弹窗）
```

**文字层级：**
```
--text-primary   hsl(220, 10%, 93%)   主内容
--text-secondary hsl(220, 10%, 70%)   次要
--text-muted     hsl(220, 10%, 50%)   弱化
```

**语义色（三种职责：状态/优先级/交互）：**
```
Action 蓝 #3B82F6 / Success 绿 #10B981 / Warning 琥珀 #F59E0B / Danger 珊瑚 #FF6B6B / Info 靛蓝 #6366F1
```

**关键规则**：不用纯黑、红色只留给"必须行动/错误"、深色降饱和、用明度表达层级。

**App Shell 布局**：
```
┌──────────────────────────────────────────────┐
│ [Logo]  Global Search(⌘K)  [Alerts] [User] [Theme] │
├────────┬─────────────────────────────────────┤
│ Nav    │  Page Header: 标题·时间·CTA          │
│ Rail   │  [ Main Content ]                   │
└────────┴─────────────────────────────────────┘
```

### 2.2 公安业务系统设计原则（DB65T4922-2025）
- **配色 ≤ 3 种**：主色（75-80%）+ 辅助色 + 点睛色
- 文字 12-36px，页面中心区 1000-1400px
- 布局以**左右布局**为主（左导航 + 右内容）

### 2.3 政企 UI 实战细节（兰亭妙微）
- 深色模式**降饱和**，不直接用浅色模式色值
- **主次按钮分层**：核心=实心，次要=线框
- **图标统一**：一套图标体系，禁止混搭线性/面性
- 数据卡片**善用视觉对比**突出核心指标

## 三、推荐方案

### 组合：vue-pure-admin 布局骨架 + 警务设计 token

**为什么这样组合：**
1. **布局**（vue-pure-admin）：顶栏 + 侧栏 + 标签页 + 内容，轻量规范，与我们当前结构一致（已验证可行）
2. **视觉 token**（UK Police Design System）：专门为警务场景设计，暗黑优先、语义色完整、明度层级体系——正好解决 FraudLens "对比度弱/层级乱"的问题
3. **不引入工程**：只提炼布局规范 + token 体系，应用到现有 18 页面，风险可控

**落地要点（对齐警务规范）：**
1. **Token 体系重做**（style.css）：
   - 背景三级：`--bg-canvas / --bg-surface-0 / --bg-surface-1 / --bg-surface-2`（用明度差表达层级）
   - 文字三级：primary / secondary / muted
   - 语义色：Action 蓝 / Success / Warning / Danger / Info
   - 间距 4px 基准、字号阶梯 12-36px、`tabular-nums` 数据字体
2. **布局**：保持顶栏+侧栏+tabs 骨架（已修复 float bug），按 App Shell 规范微调
3. **卡片**：1px 边框 + 明度层级（不用发光），hover 用 surface-1 提亮
4. **组件**：按钮主次分层、图标统一（Element Plus 一套，禁止混搭）
