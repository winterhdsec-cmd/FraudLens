- **G2 脱敏网关**：`mask_sensitive()` 对 身份证/银行卡/手机号/邮箱 仅留后 4 位；正则用 `(?<!\d)`/`(?!\d)` 而非 `\b`（中文在 Python re 属 `\w`，数字贴中文时 `\b` 失效→漏掩）；接 `llm_wrapper` 出口 + `CLOUD_LLM_MASK`/`DISABLE_CLOUD_LLM`。
- **G3 资源级 RBAC + 修复历史库缺列 bug**：`apply_department_scope()` 按 `current_user['department']` 行级过滤（admin/auditor 豁免，空部门看全部，老数据 `department=''` 默认可见）；研判后把 session 关联案件写回 `department`。**关键修复**：G3 此前只在 ORM 模型加 `department` 列，`create_all()` 不会 ALTER 已有表 → 运行期 `Unknown column 'cases.department'`、`GET /api/cases` 必 500。`database/__init__.py` 新增幂等 `migrate()`（查 information_schema，缺失才 `ALTER TABLE ... ADD COLUMN department VARCHAR(100) NOT NULL DEFAULT ''` + 索引），于 `init_db()` 调用。
- **G4 CORS 白名单**：`allow_origins` 改由 env `CORS_ALLOWED_ORIGINS`(逗号分隔)读取，去 `'*'`；非白名单 Origin 预检不回 `Access-Control-Allow-Origin`。
- **G5 安全响应头**：`SecurityHeadersMiddleware(BaseHTTPMiddleware)` 注入 nosniff / DENY / no-referrer / `1; mode=block`；HSTS 仅 `TLS_ENABLED=1` 下发。
- **G6 全局限流 + 修复 `import time` 缺失 bug**：`RateLimitMiddleware(BaseHTTPMiddleware)` Redis token-bucket（user+IP，`RATE_LIMIT_REQUESTS`/`RATE_LIMIT_WINDOW` 默认 60/60s，白名单 /health /ready /docs /openapi.json /ws），Redis 不可用时回退进程内。**关键修复**：原 `_acquire()` 首行 `now = time.time()` 但模块未 `import time` → 每次请求 `NameError` 致中间件整体失效、永不 429。补 `import time` 后实测 70 连发 60 上限、第 61 次返回 429。
- **G7 审计扩覆盖**：`system.py`(研判开始/完成)、`gangs.py`(GNN 检测开始)、`reports.py`(案件报告/团伙报告/报告下载；后两者此前未鉴权，本次补 `get_current_user` + `log_operation`) 统一留痕；`operation_logs` 表实测持续写入（login + freeze_decision + 端点审计）。
