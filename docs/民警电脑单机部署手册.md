# FraudLens 民警电脑·离线单机部署手册

> 面向场景：**民警本人电脑 / 内网离线终端**，免 Docker、免外网、双击即用。
> 版本：2026-08-30 · 对应启动脚本 `start_police.bat`

---

## 一、架构（为什么能单机跑）

| 组件 | 单机版怎么解决 | 需不需要额外装 |
|---|---|---|
| 前端(18页面) | 已 `npm run build` 进入 `backend/static/`,由后端同源托管 | ❌ 免 nginx |
| 后端 FastAPI | 用 `venv-full`(系统Python3.10 + 全量深度学习依赖)直接起 | ❌ 免 Docker |
| Redis | 后端启动时自动拉起 `backend/vendor/redis` 便携版 | ❌ 零依赖 |
| BGE 语义模型 | `backend/bge-large-zh-v1.5` 随包携带,本地加载 | ❌ 免外网 |
| EasyOCR | 模型已缓存 `~/.EasyOCR` | ✅ 首次需一次镜像(可离线拷) |
| 数据库 | MySQL 8.0 | ✅ **唯一硬依赖** (见下节) |
| 云端 LLM | 默认关闭(`DISABLE_CLOUD_LLM=1`),涉敏数据不出域 | ❌ 默认关 |

**一句话**:民警电脑只需装一个 MySQL,整套系统就能本地跑起来,全程不上传任何案件数据。

---

## 二、唯一硬依赖:MySQL 的两种装法

### 方案 A(推荐):便携版 MySQL(免安装,纯拷贝)

1. 在开发机下载 **MySQL Community Server 8.x zip 版**(Windows (x86, 64-bit), ZIP Archive)。
2. 解压到 `backend\vendor\mysql\`(即 `backend\vendor\mysql\bin\mysql.exe` 存在)。
3. 首次初始化(在开发机或民警电脑做均可):
   ```
   cd backend\vendor\mysql
   bin\mysqld.exe --initialize-insecure --basedir=. --datadir=.\data
   ```
   > `--initialize-insecure` 会让 root 免密,便于脚本自动接;正式用再设强密码。
4. 启动(可注册为 Windows 服务,或每次用脚本拉起)。

### 方案 B:安装版(经典)

- 装 MySQL Community 8.0,记录 root 密码。
- 把 root 密码填入 `backend\key.env` 的 `DB_PASSWORD=`。

> **无论哪种方式**,都要保证 `backend\key.env` 里 `DB_HOST/DB_PORT/DB_USER/DB_PASSWORD` 指向这台机器的 MySQL,且库名 `fraudlens` 存在(首次由后端 `create_all` 自动建表,无需手动建表)。

## 三、打包到民警电脑(离线分发)

民警电脑往往**无外网或无 Docker**,把整套做成可拷贝目录即可:

```
FraudLens/
├── backend/
│   ├── venv-full/                # 完整 Python 环境(必须一起拷)
│   ├── bge-large-zh-v1.5/        # BGE 大模型(本地)
│   ├── static/                   # 前端产物(由 start_police.bat 自动内置)
│   ├── vendor/
│   │   ├── redis/                # 便携 Redis
│   │   └── mysql/                # 便携 MySQL(方案A)
│   ├── key.env                   # 数据库/密钥配置
│   └── ...源码
├── start_police.bat
└── stop_police.bat
```

**打包清单(幂等执行一遍即可)**:
1. `backend/venv-full/` (约几个GB,含 torch/transformers)——必须整个拷,漏了起不来。
2. `backend/bge-large-zh-v1.5/` ——漏了会静默降级,团伙识别失效。
3. `frontend/` 构建 → 已进 `backend/static/`。
4. 若本机没装 EasyOCR 模型,把 `~/.EasyOCR/model` 一并拷到民警电脑 `%USERPROFILE%\.EasyOCR\`(甚至无需:缺了会在线下,需一次外网;内网环境务必预拷)。
5. `backend/key.env`(注意:里面若含 DeepSeek key,交给民警前建议置为空或改 `DISABLE_CLOUD_LLM=1`)。

## 四、安全加固(交付前必做,防"裸奔")

民警电脑数据涉敏,**务必执行**:

| 项 | 改法 | 位置 |
|---|---|---|
| 关闭云端LLM | `DISABLE_CLOUD_LLM=1` | `key.env`(start_police.bat 已默认置1) |
| 改admin密码 | 登录后立即在"用户管理"改密 | 前端 |
| 改JWT密钥 | `JWT_SECRET_KEY=` 换随机长串 | `key.env` |
| 改DB密码 | 若方法A,`--initialize-insecure` 后手动 `ALTER USER` 设强密码 | MySQL |
| 改Redis密码 | `REDIS_PASSWORD=` | `key.env` |
| 开启HTTPS | 生产建议;单机内网演示可先HTTP | 视部署形态 |
| 数据留痕 | 操作审计日志已内置(`log_operation`),确认开启 | 后端 |

## 五、首次使用流程(给民警的操作路径)

1. 双击 `start_police.bat`。
2. 等约 30-60 秒(BGE 首次加载),浏览器自动打开 `http://localhost:5003`。
3. 用 `admin/admin123` 登录 → **立即改密**。
4. 录入线索(文本/CSV/截图)→ 看串并成网 → 出研判报告。
5. 用毕关闭 → `stop_police.bat`。

## 六、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `[错误] 未找到 Python 环境` | 没拷 `venv-full` | 补拷完整 venv |
| 卡在"正在启动"很久 | BGE 大模型首次加载(几十秒) | 等,别关;看 `backend/server.log` |
| `/health` 一直非200 | 可能 MySQL 没起/密码不对 | 核对 `key.env` 与 MySQL |
| 登录报"数据库错误" | MySQL 未初始化/库不存在 | 确认 MySQL 在跑 + `fraudlens` 库存库存在 |
| OCR 卡死/报错 | 无外网且 EasyOCR 模型未预置 | 预拷 `~/.EasyOCR/model` |
| 团伙识别为空/不准 | BGE 模型缺失静默降级 | 确认 `backend/bge-large-zh-v1.5` 完整 |

## 八、待办/已知边界(诚实)

- **不完全离线**:EasyOCR 首次模型下载需一次外网(或预拷缓存)——若民警端无外网,打包时务必预带 `~/.EasyOCR/model`。
- **MySQL 仍是唯一手动依赖**:脚本已尽力降级到"便携版免安装",但无法内置进 venv(体积/许可)。
- 单机版未做多进程横向扩展(民警单机场景不需要);需要高可用仍走 docker-compose。
