# FraudLens 部署手册

> **文档编号**: OPS-DEPLOY-001 | **版本**: v1.0 | **日期**: 2026-08-04  
> **适用**: Docker Compose 全栈部署

---

## 1. 环境要求

| 组件 | 最低版本 | 说明 |
|------|----------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 多容器编排 |
| 内存 | 12 GB（推荐 16 GB） | BGE 模型加载需 4GB，PyTorch 需 2GB |
| 磁盘 | 20 GB（含模型+数据） | BGE 嵌入模型 1.3GB |
| OS | Windows 10+/Linux | macOS 需额外配置 |

## 2. 快速启动（Docker Compose）

### 2.1 配置环境变量

```bash
# 复制 .env.docker 或直接编辑项目根目录 .env
cp .env.docker .env
# 编辑 .env，至少修改:
#   DB_PASSWORD=你的数据库密码
#   DEEPSEEK_API_KEY=你的APIKey（可选，可关闭）
#   JWT_SECRET_KEY=你的JWT密钥
```

### 2.2 启动全部服务

```bash
cd E:\FraudLens
docker compose up -d
```

### 2.3 验证

```bash
# 健康检查
curl http://localhost/health
# → {"status":"healthy"}

# 就绪检查
curl http://localhost/ready
# → {"status":"ready","checks":{"mysql":"ok","redis":"ok","gnn_model":"loaded"}}

# 前端
浏览器打开 http://localhost

# API 文档
浏览器打开 http://localhost:5003/docs
```

## 3. 多环境部署

### 开发环境

```bash
docker compose -f docker-compose.dev.yml up -d
# 特点: 源码挂载（修改即时生效）、暴露调试端口
```

### 生产环境（默认）

```bash
docker compose up -d
# 特点: 构建产物运行、不挂载源码
```

### 高可用环境（MySQL 主从 + Redis Sentinel）

```bash
docker compose --profile ha up -d
# 特点: MySQL 主从复制（GTID）、Redis 哨兵（1主2从3哨兵）
```

## 6. 配置项说明

### 关键环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DB_PASSWORD` | — | MySQL root 密码 |
| `DB_NAME` | fraudlens | 数据库名 |
| `REDIS_PASSWORD` | — | Redis 密码 |
| `DEEPSEEK_API_KEY` | — | DeepSeek API Key |
| `DEEPSEEK_MODEL` | deepseek-chat | 使用的模型 |
| `DISABLE_CLOUD_LLM` | 1 | **1=关闭云端LLM（推荐警务环境）** |
| `CLOUD_LLM_MASK` | 1 | 启用云端LLM时强制脱敏 |
| `ENABLE_REFLECTION_LOOP` | 1 | 1=启用反思闭环 |
| `JWT_SECRET_KEY` | — | JWT 签名密钥（务必修改） |
| `TLS_ENABLED` | 0 | 1=启用 HTTPS（需配证书路径） |
| `ENV` | production | dev/staging/production |

## 8. 启停与更新

### 停止

```bash
docker compose down           # 停止所有服务
docker compose down -v        # 停止并删除数据卷（危险！）
```

### 重启单个服务

```bash
docker compose restart backend
docker compose restart celery
```

### 更新代码

```bash
git pull
docker compose build backend    # 重新构建镜像
docker compose up -d backend    # 更新后端
```

## 9. 纯内网部署（公安网）

### 9.1 构建离线镜像

```bash
# 在有网络的机器上构建并导出
docker compose build
docker save fraudlens-backend mysql:8.0 redis:7-alpine minio/minio nginx:alpine -o fraudlens_images.tar

# 在公安网机器上导入
docker load -i fraudlens_images.tar
```

### 9.2 纯离线配置

```bash
# 编辑 .env
DISABLE_CLOUD_LLM=1     # 关闭云端 LLM
TLS_ENABLED=1           # 启用 HTTPS（需先配置证书）
```

### 9.3 生成自签证书（测试用）

```bash
bash scripts/gen_tls.sh
# 生成 certs/fullchain.pem + certs/privkey.pem
```

## 10. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 启动后 /ready 返回 mysql 不健康 | MySQL 初始化未完成 | 等待 30s 重试 |
| Celery worker 不启动 | Redis 连接失败 | 检查 REDIS_PASSWORD |
| BGE 模型加载失败 | 内存不足 | 需要 ≥ 4GB 空闲内存 |
| 研判返回空结果 | 云端 LLM 关闭且案例复杂 | 开启 DISABLE_CLOUD_LLM=0 |
| 端口冲突 | 80/3306/6379 被占用 | 修改 docker-compose.yml 端口映射 |
