# 项目申报书降 AI 感方案

> 目标：在不改变技术内容与数据的前提下，降低文本的"机器生成感"，使其更贴近警校学生的手写风格。
> 原则：只做局部措辞替换，不做内容增删；保留技术术语（反思闭环、共识分析等）与官方文书惯用的"一是/二是/三是"结构。

## 二、替换规则

### 规则 1：解释性破折号 → 冒号 / 逗号
破折号用于"引出解释"时，改为冒号（：）；用于"补充说明、语气停顿"时，改为逗号（，）。
**保留**：图题中的破折号（如"关系图谱——案件、团伙、资金多维关联网络"）、流程箭头（→）与"提出—质疑—复核"中的连接号。

### 规则 2：AI 套话词汇替换
- "最可靠的抓手" → "最可靠的证据"（抓手是典型 AI/公文套话）
- "赋能" 视语境替换为"支撑/服务/用于"等具体动词

### 规则 3：句式微调（仅对明显生硬的句子）
- "三者兼备——这是团队……的底气" → "三者兼备，是团队……的底气"（去掉"这是"的强调句式）
