## 十、答辩 10 问（只答"用什么数据"）

1. **走访了几家单位？** → 已完成 2026.6.4 学院反诈讲座现场访谈武汉市反诈中心民警；系统走访与工单回访 9—10 月进行。**没做就说"还在进行"，不编。**
2. **ARI 0.9154±0.1214 标准差是不是太大？** → 承认。干净小样本上无监督 selfsup（0.922）仍略优于 hybrid（0.913），这是已定位的 limitation；价值在重噪/碰撞场景（0.95）与可复现性（固定种子 + sha256 确定性 hash，跨进程结果一致）。
3. **GraphSAGE 为什么不行？** → 基线出现表征塌缩（ARI 0.3043），单通道同构聚合抓不住异构语义，这正是上 HAN 多矩阵元路径 + 双通道共识的理由。
4. **和现有公安平台比强在哪？** → 现有系统靠规则库与人工串并；我们不依赖人工标签、可增量挂团、**且证据不足时不出结论**。
5. **数据哪来的？涉密吗？** → 已脱敏＋仿真异构图（40/200/1000 案）＋ Elliptic 公开基准；全程本地 BGE 推理，案件数据不外传；已签保密承诺书。
6. **部署要什么硬件？** → 纯 CPU 即可，刻意适配内网无 GPU 环境。
7. **等保做了吗？** → **没有**，按公安内网安全规范设计，测评在实际部署后开展（P7 已改口径，别答"满足三级"）。
8. **没注册公司怎么谈商业模式？** → 我们是创意组，定位＝创意＋原型＋可验证实证，商业部分只做计划与测算（项目制 30~80 万＋年订阅 5~10 万）。
9. **老师做了什么？** → 吴燕波老师在网络犯罪侦查方向给予指导（侦查逻辑校准、访谈组织）；按规则教师不属成员，全部开发由学生完成。
10. **下一步？** → 解锁 S17（先删签约/测评字样）：9—10 月完成反诈中心实地走访与工单回访，推进增量匹配在大样本上的验证，把 200 案场景召回再提上去。
