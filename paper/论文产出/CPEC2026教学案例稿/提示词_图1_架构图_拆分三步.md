# 图1 FraudLens 系统总体架构图 —— 三步拆分提示词（学术 Visio 风 · LLMDS 式"中枢+增强+分支"组织）

> **用法**：以下三段可直接贴进 Next AI Drawio 的 AI 生成框（支持续改就顺序叠加；不支持就只用【第1步】确认布局，第2/3步当手画清单）。拿到 `.drawio` 源文件后，也建议按本规范在 draw.io 里手动精修。
> **目标风格**：参考 LLMDS（图2）的学术论文架构图——**以 LangGraph 内核为中枢，输入在左、输出在右、上方挂增强模块、菱形判断分两支、结果反馈回中枢**；扁平黑白灰、可黑白打印。

---

## 统一风格规范（必须符合，否则不像学术图）

- **配色**：仅 黑 `#333333`、白 `#FFFFFF`、浅灰（背景岛 `#F5F5F5` / 标题栏 `#E8E8E8`）。禁止彩色、渐变、阴影。
- **字体**：中文 `Microsoft YaHei`（或 `SimHei`），英文数字 `Arial`；大岛标题 13pt 加粗，子模块 9–10pt 常规。
- **形状**：模块一律**直角矩形**（`rounded=0`），黑色细边框 `strokeWidth=1.5`；大岛用浅灰背景，岛内子模块用白色。
- **箭头**：`endArrow=block`，颜色 `#333333`；**实线=主流程/数据流**，**虚线=反馈环/可选路径**。
- **图标**：数据库用圆柱、不用厂商 logo；模块内不堆图标，用文字即可。
- **层次**：浅灰大岛圈出"视觉岛"；**主流程横向贯通**，增强模块从上方虚线/实线挂靠。
- **文字**：简体中文，不溢出框。

## 第 1 步 · 骨架（中枢 + 增强岛 + 输入/输出 + 菱形判断，不填细节）

【以画布中央为 LangGraph 反诈研判内核，左右为输入/输出，上方为增强支撑，形成 LLMDS 式布局】

2. **左侧浅灰岛**：标题栏「输入层 / 案情接入」，作为流程入口。

3. **右侧浅灰岛**：标题栏「应用服务 / 决策输出」，作为流程出口。

4. **左上方浅灰岛**：标题栏「数据增强 / RAG 检索」，挂靠数据相关能力。

5. **右上方浅灰岛**：标题栏「模型支撑 / 双通道 GNN + LLM」，挂靠模型相关能力。

6. **底部横向浅灰长条**：标题栏「工程可信保障」，先留空。

【布局硬要求】
- 中央内核岛最大，位于画布正中；
- 输入层在中央左侧、应用服务在中央右侧，三者横向贯通；
- 数据增强岛在输入层正上方；模型支撑岛在应用服务正上方，两岛略高于中央岛；
- 底部支撑条横贯四岛下方；
- 图下方居中写标题：「图1 FraudLens 反诈研判系统总体架构图」。

【禁止】不画子模块、不画箭头——只确认"一核 + 两增强岛 + 输入/输出 + 菱形判断"的位置对不对。

## 第 2 步 · 填充内部子模块（白色直角矩形，不改岛位置大小）

（在骨架上继续）给各岛填充白色直角子模块（`rounded=0`，白底黑边 `1.5`），**不要改动岛的位置和大小**：

1. **输入层 / 案情接入岛**（竖向 3 个）：
   - 民警研判界面（Vue3 + Element Plus）
   - 案情录入 / 交易流水导入
   - 研判请求发起

2. **数据增强 / RAG 检索岛**（2×2 网格）：
   - MySQL（案情库 / 交易流水）
   - Redis 缓存
   - BGE-large 本地嵌入
   - 检索器 / 向量数据库

3. **模型支撑 / GNN + LLM 岛**（2×2 网格）：
   - DeepSeek 云端大模型
   - GNN 双通道（GraphSAGE / HAN）
   - 对比学习模型
   - LoRA / 本地参数高效微调（可选，占位即可）

4. **中央内核岛**（竖向 5 个白色流程节点 + 1 个菱形）：
   - 规划 Plan
   - 预处理 Preprocess（字段对齐 · 数据脱敏）
   - 分析 Analyze（结构通道 / 文本通道）
   - 聚类 Cluster
   - 反思 Reflect（置信度评估 · 规则触发）
   - 菱形：「置信度是否足够？」（放在 Cluster 与 Reflect 之间或 Reflect 之后）

5. **应用服务 / 决策输出岛**（竖向 4 个）：
   - 候选结果
   - 规则 vs AI 建议对比
   - 冻卡决策
   - 人工审核 · 审计日志 · 可视化

6. **底部工程可信保障条**：数据不出域 · RBAC 鉴权 · 审计溯源 · 可解释性 · 多级降级。

【要求】白色子模块、直角、黑细边；中文不溢出；同一岛内等距对齐。

## 第 3 步 · 连线、菱形分支、反馈环（学术 Visio 风收尾）

（在已填充图上继续）添加连接与闭环：

1. **主流程（黑实线箭头）**：
   输入层 → 数据增强岛（数据支撑） → 中央内核（Plan→Preprocess→Analyze→Cluster→Reflect）。

2. **模型支撑到内核（黑虚线/实线）**：模型支撑岛引实线/虚线到「分析 Analyze」和「反思 Reflect」，标注「模型能力注入」。

3. **内核内部流程 + 菱形分支**：
   - Plan → Preprocess → Analyze → Cluster → 菱形「置信度是否足够？」
   - **是**（实线）：→ Reflect → 应用服务岛（候选结果 / 规则对比 / 冻卡决策）
   - **否**（虚线）：从菱形直接返回「规划 Plan」，标注「置信度低 / 规则触发 → 返回规划」

4. **顶部反馈环（黑虚线）**：从「应用服务·人工审核」顶部绕回「输入层·案情录入」顶部，标注「人工审核反馈 Human-in-the-loop」。

5. **审计/可视化输出（黑实线）**：应用服务 → 人工审核 · 审计日志 · 可视化（可接小电脑/界面图标占位，但不用真实 logo）。

6. **底部支撑条**：不连箭头，作为文字条横在底部。

7. **终检**：箭头标签不压线、文字不溢出、中枢与增强岛层次清晰、整图仅黑白灰。
