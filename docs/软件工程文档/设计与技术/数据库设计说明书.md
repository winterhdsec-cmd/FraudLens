## 2. 核心表结构

### 2.1 users — 用户表

```sql
CREATE TABLE users (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    username    VARCHAR(64)  NOT NULL UNIQUE,
    password    VARCHAR(256) NOT NULL,        -- bcrypt 哈希
    role        VARCHAR(16)  DEFAULT 'police', -- admin / police / auditor
    department  VARCHAR(128),                  -- 所属部门（分局/派出所）
    email       VARCHAR(128),
    is_active   BOOLEAN      DEFAULT TRUE,
    created_at  DATETIME     DEFAULT NOW(),
    updated_at  DATETIME     DEFAULT NOW() ON UPDATE NOW()
);
```

### 2.2 cases — 案件表（核心实体）

```sql
CREATE TABLE cases (
    id              VARCHAR(32) PRIMARY KEY,       -- CASE_001
    title           VARCHAR(256),
    description     TEXT,                           -- 案情描述
    scam_type       VARCHAR(64),                    -- 刷单返利/杀猪盘/冒充公检法...
    city            VARCHAR(64),
    amount          DECIMAL(18,2),                  -- 涉案金额
    incident_time   DATETIME,                       -- 案发时间
    status          VARCHAR(32) DEFAULT 'pending',  -- pending/analyzing/completed/archived
    source          VARCHAR(32),                    -- manual/upload/api
    raw_text        TEXT,                           -- 原始材料文本
    risk_score      FLOAT,
    created_by      INT REFERENCES users(id),
    created_at      DATETIME DEFAULT NOW(),
    updated_at      DATETIME DEFAULT NOW() ON UPDATE NOW(),
    INDEX idx_scam_type (scam_type),
    INDEX idx_city (city),
    INDEX idx_status (status)
);
```

### 2.3 victims — 受害者表

```sql
CREATE TABLE victims (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    case_id     VARCHAR(32) REFERENCES cases(id) ON DELETE CASCADE,
    name        VARCHAR(64),
    phone       VARCHAR(32),
    id_card     VARCHAR(32),
    age         INT,
    gender      VARCHAR(8),
    occupation  VARCHAR(64),
    loss_amount DECIMAL(18,2),
    INDEX idx_case (case_id)
);
```

### 2.4 phones — 手机号表

```sql
CREATE TABLE phones (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    number      VARCHAR(32) NOT NULL,
    type        VARCHAR(32),       -- 嫌疑人/受害人/中转号
    carrier     VARCHAR(32),       -- 运营商
    city        VARCHAR(64),
    INDEX idx_number (number)
);
```

### 2.5 accounts — 账户表

```sql
CREATE TABLE accounts (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    account_no  VARCHAR(64) NOT NULL,       -- 脱敏卡号（仅后 4 位明文）
    bank_name   VARCHAR(128),               -- 开户行
    holder_name VARCHAR(64),                -- 户名（脱敏）
    account_type VARCHAR(32),               -- 一级卡/二级卡/三级卡...
    total_in    DECIMAL(18,2),              -- 累计流入
    total_out   DECIMAL(18,2),              -- 累计流出
    n_tx_in     INT,                        -- 流入交易笔数
    n_tx_out    INT,                        -- 流出交易笔数
    is_suspect  BOOLEAN DEFAULT FALSE,      -- 是否嫌疑账户
    INDEX idx_account_no (account_no),
    INDEX idx_is_suspect (is_suspect)
);
```

### 2.6 perpetrators — 违法者表

```sql
CREATE TABLE perpetrators (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    name        VARCHAR(64),                -- 脱敏姓名
    id_card     VARCHAR(32),                -- 脱敏身份证号
    phone       VARCHAR(32),
    role        VARCHAR(32),                -- 引流/实施/洗钱/组织者
    city        VARCHAR(64),
    INDEX idx_role (role)
);
```

### 2.7 case_accounts — 案件-账户关联表

```sql
CREATE TABLE case_accounts (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    case_id     VARCHAR(32) REFERENCES cases(id) ON DELETE CASCADE,
    account_id  INT REFERENCES accounts(id) ON DELETE CASCADE,
    role        VARCHAR(32),                -- 收款账户/中转账户/洗钱账户
    amount      DECIMAL(18,2),
    UNIQUE (case_id, account_id)
);
```

### 2.8 case_perpetrators — 案件-违法者关联表

```sql
CREATE TABLE case_perpetrators (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    case_id         VARCHAR(32) REFERENCES cases(id) ON DELETE CASCADE,
    perpetrator_id  INT REFERENCES perpetrators(id) ON DELETE CASCADE,
    role            VARCHAR(32),
    UNIQUE (case_id, perpetrator_id)
);
```

### 2.9 fund_flows — 资金流水表

```sql
CREATE TABLE fund_flows (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    from_account    VARCHAR(64) NOT NULL,
    to_account      VARCHAR(64) NOT NULL,
    amount          DECIMAL(18,2),
    tx_time         DATETIME,
    tx_type         VARCHAR(32),            -- 转账/消费/取现
    remark          VARCHAR(256),
    source_file     VARCHAR(256),           -- 来源文件
    created_at      DATETIME DEFAULT NOW(),
    INDEX idx_from (from_account),
    INDEX idx_to (to_account),
    INDEX idx_time (tx_time)
);
```

### 2.10 gangs — 团伙表

```sql
CREATE TABLE gangs (
    id              VARCHAR(32) PRIMARY KEY,    -- GANG_001
    name            VARCHAR(128),
    n_cases         INT,
    n_accounts      INT,
    n_perpetrators  INT,
    total_amount    DECIMAL(18,2),
    confidence      FLOAT,                      -- [0,1] 客观置信度
    gate_decision   VARCHAR(32),                -- 建议冻结 / 待人工复核
    has_reflux      BOOLEAN,                    -- 是否检出资金回流闭环
    risk_level      VARCHAR(16),                -- high/medium/low
    cluster_method  VARCHAR(32),                -- HAN/GraphSAGE/Louvain/KMeans
    created_at      DATETIME DEFAULT NOW(),
    updated_at      DATETIME DEFAULT NOW() ON UPDATE NOW()
);
```

### 2.11 gang_members — 团伙成员表

```sql
CREATE TABLE gang_members (
    id      INT AUTO_INCREMENT PRIMARY KEY,
    gang_id VARCHAR(32) REFERENCES gangs(id) ON DELETE CASCADE,
    case_id VARCHAR(32) REFERENCES cases(id) ON DELETE CASCADE,
    UNIQUE (gang_id, case_id)
);
```

### 2.12 freeze_decisions — 冻卡决策审计表

```sql
CREATE TABLE freeze_decisions (
    id              INT AUTO_INCREMENT PRIMARY KEY,
    gang_id         VARCHAR(32) REFERENCES gangs(id),
    account_id      INT REFERENCES accounts(id),
    confidence      FLOAT,
    gate_decision   VARCHAR(32),
    reason          TEXT,                       -- 决策依据（回流闭环/共享账号/金额...）
    decided_by      INT REFERENCES users(id),
    review_status   VARCHAR(32) DEFAULT 'pending',  -- pending/approved/rejected/executed
    reviewed_by     INT REFERENCES users(id),
    reviewed_at     DATETIME,
    created_at      DATETIME DEFAULT NOW()
);
```

### 2.13 operation_logs — 操作审计表

```sql
CREATE TABLE operation_logs (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    user_id     INT REFERENCES users(id),
    action      VARCHAR(64) NOT NULL,           -- login/analyze/freeze/export/config...
    target_type VARCHAR(64),                    -- case/gang/account/user
    target_id   VARCHAR(64),
    detail      JSON,                           -- 操作详情
    ip_address  VARCHAR(64),
    created_at  DATETIME DEFAULT NOW(),
    INDEX idx_user (user_id),
    INDEX idx_action (action),
    INDEX idx_time (created_at)
);
```

### 2.14 reports — 研判报告表

```sql
CREATE TABLE reports (
    id          VARCHAR(32) PRIMARY KEY,
    case_id     VARCHAR(32) REFERENCES cases(id),
    gang_id     VARCHAR(32) REFERENCES gangs(id),
    title       VARCHAR(256),
    content     LONGTEXT,                      -- Markdown/JSON 报告内容
    file_path   VARCHAR(512),                   -- MinIO 文件路径
    created_by  INT REFERENCES users(id),
    created_at  DATETIME DEFAULT NOW()
);
```

### 2.15 knowledge_items — 知识库表

```sql
CREATE TABLE knowledge_items (
    id          INT AUTO_INCREMENT PRIMARY KEY,
    title       VARCHAR(256),
    content     TEXT,
    category    VARCHAR(64),                    -- 诈骗手法/法律法规/案例
    embedding   JSON,                           -- BGE 向量
    version     INT DEFAULT 1,
    is_active   BOOLEAN DEFAULT TRUE,
    created_at  DATETIME DEFAULT NOW()
);
```

## 3. ER 关系总图

```
users ──1:N── cases ──1:N── victims
                  │
                  ├── N:M ── accounts ──1:N── fund_flows(from/to)
                  │                  │
                  ├── N:M ── perpetrators  │
                  │                  │      │
                  └── N:M ── gangs ──┘──────┘
                           │
                           ├── 1:N ── gang_members
                           ├── 1:N ── freeze_decisions
                           └── 1:N ── reports

users ──1:N── operation_logs
users ──1:N── freeze_decisions (decided_by/reviewed_by)
```

## 4. 索引策略

| 表 | 索引 | 类型 | 用途 |
|------|------|------|------|
| cases | idx_scam_type | B-Tree | 按诈骗类型筛选 |
| cases | idx_status | B-Tree | 按状态筛选 |
| accounts | idx_account_no | B-Tree | 卡号精确匹配 |
| accounts | idx_is_suspect | B-Tree | 嫌疑账户筛选 |
| fund_flows | idx_from | B-Tree | 出账查询 |
| fund_flows | idx_to | B-Tree | 入账查询 |
| fund_flows | idx_time | B-Tree | 时间范围查询 |
| operation_logs | idx_user+action+time | 复合 | 审计追溯 |

## 5. 数据安全设计

| 措施 | 实现 |
|------|------|
| 敏感字段脱敏 | 身份证/卡号/手机号存储时仅保留后 4 位（`tools/mask.py`） |
| 密码哈希 | bcrypt（werkzeug） |
| 审计日志 | `operation_logs` append-only，不提供删除接口 |
| 行级隔离 | `apply_department_scope(query, user)` 按 department 过滤 |
| 备份 | MySQL 定时 dump + binlog 归档 |
| 数据不出域 | 全部 MySQL 本地容器，云端 LLM 默认关闭 |
