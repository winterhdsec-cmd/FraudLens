## 1. 设计目标

构建面向公安反诈中心的智能辅助研判系统，核心设计目标：

1. **研判能力**：多智能体编排 + 异构图神经网络实现"案件串并→账户扩线"两级闭环
2. **可信决策**：客观置信度门控 + 人工复核，不靠模型猜测定冻卡
3. **数据安全**：涉案数据全本地处理（数据不出域），云端 LLM 默认关闭+启用时脱敏
4. **韧性保障**：多级降级链（GNN→规则聚类，LLM→规则，BGE→TF-IDF）
5. **可审计**：全操作 append-only 留痕 + 冻卡决策双表

## 3. 核心模块设计

### 3.1 多智能体编排模块（agents/）

```
orchestrator.py        → LangGraph StateGraph 五节点编排
  ├── plan_node        → 解析用户意图，生成执行计划
  ├── preprocess_node  → 实体抽取 + 资金流解析 + 图构建准备
  ├── analyze_node     → AnalystAgent 调用（实体/话术/角色分析）
  ├── cluster_node     → ClusterAgent 调用（GNN 团伙发现 + 实体并案）
  └── reflect_node     → 质量评估 + 条件边回连（未收敛→analyze，收敛→END）

analyst_agent.py       → 案情分析（证据提取/相似案检索/风险评估/报告生成）
cluster_agent.py       → 团伙发现（GNN 聚类 + 共享实体并案 + 回流检测 + 置信度门控）
chat_agent.py          → 独立旁路对话（不进研判流水线）
reflect_agent.py       → 反思评估（质量分计算 + 策略调整建议）
registry.py            → Agent 注册表（可插拔）
```

**反思质量分公式**:
```
quality_score = 0.5 × silica_score + 0.25 × has_gangs + 0.25 × has_analysis
触发重算: quality_score < 0.6 且 retry_count < max_iter
重算策略: use_gnn=False, 调小聚类粒度
```

### 3.2 图神经网络模块（gnn/）

```
han_model.py           → HAN 异构图注意力网络（5 元路径 + 语义注意力）
  ├── HANLayer         → 节点级注意力（单条元路径）
  ├── SemanticAttention→ 语义级注意力（融合多条元路径）
  └── GraphCL Trainer  → 对比学习预训练（边丢弃 + 特征掩码，NT-Xent）

gnn_model.py           → GraphSAGE 资金链模型（加权邻接 log1p）
graph_builder.py       → 异构图构建器
  ├── 节点: case/victim/phone/scam_type/city/account/perpetrator
  ├── 边:   has_victim/has_phone/is_type/in_city/similar(话术)
  ├── 资金边: share_account/share_perpetrator/fund_flow(有向+金额+时间)
  └── 特征: 统计特征（去 hash）+ BGE 语义嵌入

gang_detector.py       → 团伙检测器
  ├── detect()         → 完整检测流程
  ├── _generate_gang_info → 团伙摘要（关联账户/违法者/闭环）
  ├── detect_reflux_cycles → 资金回流闭环检测
  └── 置信度门控       → 4 因子加权 + gate_decision

community.py           → 社区发现（Louvain 降级基线）
synthetic_data.py      → 合成数据生成器（固定种子，可复现）
eval_framework.py      → 评测框架（NMI/ARI/F1 报告）
ablation.py            → 消融实验（去反思/去GNN/去门控）
```

### 3.3 核心支撑模块（core/）

```
config.py              → 配置管理（多环境：dev/staging/prod）
security.py            → 安全模块（JWT/Prompt注入检测/输入验证）
circuit_breaker.py     → 熔断器（防止级联故障）
checkpoint.py          → 检查点管理（状态持久化 + 故障恢复）

embedding.py           → 嵌入模型（BGE-large 单例，本地推理）
metrics.py             → 指标收集（任务成功率/工具调用/LLM调用）
agent_runtime.py       → Agent 运行时（生命周期管理）
rate_limiter.py        → 限流器（Redis token-bucket）
health_monitor.py      → 健康监控
```

## 4. 数据流设计

### 4.1 研判主流程

```
用户上传案件 → POST /api/system/agent-analyze
  → orchestrator.run()
    → plan_node: 解析意图
    → preprocess_node: 实体抽取 + 资金流解析
    → analyze_node: AnalystAgent 分析（证据/相似案/风险）
    → cluster_node:
        1. graph_builder.build() → 异构图
        2. HAN.encode() → 案件嵌入
        3. KMeans/Louvain → 团伙聚类
        4. gang_detector.detect() → 回流检测 + 置信度门控
        5. 实体关联并案 (cluster_by_entities)
    → reflect_node:
        若 quality_score < 0.6 → 回连 analyze_node（关 GNN，调小粒度）
        若 quality_score ≥ 0.6 → END
  → 返回: 团伙列表 + 冻卡建议 + 研判报告
```

### 4.2 降级链设计

```
LLM 分析     → 不可用 → 正则规则提取
GNN 聚类     → 不可用 → UMAP + HDBSCAN
HDBSCAN      → 不可用 → 规则分组（按诈骗类型+城市）
BGE 嵌入     → 不可用 → TF-IDF + hash one-hot
云端 LLM     → DISABLE_CLOUD_LLM=1 → 本地规则（默认）
```

### 4.3 数据不出域设计

```
关系数据（案件/实体/资金流/权限/审计） → 本地 MySQL
图结构                                  → 内存 networkx（研判时从 MySQL 重建）
向量嵌入                                → 本地 BGE-large 推理
OCR 原件 + 导出报告                     → 本地 MinIO
云端 LLM                                → 默认关闭；启用时 mask_sensitive() 脱敏
```

## 5. 安全设计

### 5.1 安全链路

```
请求 → Nginx(TLS 终止·路径就绪) → 限流(Redis token-bucket)
  → JWT 鉴权(全路由 get_current_user) → RBAC(角色+部门行隔离)
  → 审计中间件(log_operation) → 脱敏(mask_sensitive)
  → 业务逻辑 → 安全响应头 → 响应
```

## 7. 技术选型理由

| 技术 | 理由 |
|------|------|
| FastAPI | 异步原生、Pydantic 自动验证、OpenAPI 文档 |
| LangGraph StateGraph | 反思闭环需要条件边回连 → 比手写编排更可维护 |
| HAN (异构图注意力) | 案件异构节点类型（case/account/perpetrator/type/city/text）天然需要异构建模 |
| GraphCL 预训练 | 案件标注稀缺，自监督不依赖团伙标签 |
| BGE-large-zh | 中文语义嵌入 SOTA，本地 1.3GB，数据不出域 |
| MySQL + Redis | 公安系统标准组合，运维成熟 |
| Docker Compose | 单机全栈部署，学生可维护 |
| Celery | 研判任务异步化，避免 HTTP 超时 |
