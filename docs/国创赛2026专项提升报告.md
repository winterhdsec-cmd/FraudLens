## 七、Agent 增强：并案复核层（2026-08-28 补充）

**决策**：保持"GNN + 多 Agent"混合架构，**不改成纯 Agent 判断**（合成数据上纯语义聚类 0.9367 已近天花板，HAN 0.9154，纯 Agent 判断不会更高且不可规模化）。Agent 增强落点在**复核解释层**，强化"反思闭环"卖点。

### 7.1 架构定位

```
GNN（结构挖掘：共享账户/资金链路/异构图谱）   ← 判断主力
   ↓ 聚类结果（团伙划分）
Agent 复核层（新增 2 个 skill）              ← 本阶段工作
   ├─ Skill A 并案依据解释器：为每个团伙生成"共享账户/话术指纹/资金链路"三要素人话解释
   └─ Skill B 误并案探测器：用已知反例复查聚类结果，标出可疑并案
   ↓
置信度门控（决定采信/降级）                 ← 已有
```

### 7.2 两个 Skill 的价值

| Skill | 功能 | 演示价值 | 论文价值 |
|---|---|---|---|
| **并案依据解释器** | 每个团伙给出"为什么这些案件是一伙"的三要素解释（共享账户/话术指纹/资金链路） | 评委看到 AI"说得出为什么"，非黑盒 | 方法章节"可解释性"小节 + 评估指标（解释覆盖率） |
| **误并案探测器** | 用已知非同一团伙反例复查，标出可疑并案 | 直接演示"反思闭环"：AI 自我校验 | 消融实验（+误并探测器 的 F1/精度变化）+ 对应"反思闭环"专利点 |

### 7.3 实现计划

1. Skill A：输入 GNN 团伙划分 → 提取三要素证据 → LLM 生成自然语言解释
2. Skill B：构造少量反例对 → LLM 复查可疑并案 → 输出置信度修正建议
3. 实验：在 eval_framework 基础上加"解释覆盖率"和"误并修正精度"两个指标
