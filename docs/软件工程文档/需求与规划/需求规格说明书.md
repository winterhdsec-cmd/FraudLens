## 1. 引言

### 1.1 编写目的

本文档定义 FraudLens 系统的完整功能需求与非功能需求，作为后续设计、开发、测试与验收的唯一需求基线。

### 1.2 项目背景

电信网络诈骗犯罪呈现链条化、规模化团伙作案特征。基层反诈民警在案件研判中面临三大痛点：
- **线索碎片化**：话术文本、资金流水、报案笔录散落多源，人工串并效率低
- **团伙隐蔽化**：同一团伙控制大量账户、跨地域流窜，单案难以还原全链
- **决策风险高**：冻卡涉及公民财产权，缺乏客观评估标准

FraudLens 针对上述痛点，构建基于多智能体编排与异构图神经网络的智能辅助研判系统。

### 1.3 目标用户

| 角色 | 职责 | 核心需求 |
|------|------|----------|
| 研判员（police） | 案件录入、发起研判、查看结果 | 上传线索→获得团伙网络+冻卡建议 |
| 审批人（admin） | 审核冻卡建议、管理用户 | 审批流程、权限管理 |
| 审计员（auditor） | 查看操作审计日志 | 追溯全部操作记录 |

## 4. 数据需求

### 4.1 核心数据实体

```
Case（案件—核心实体）
  ├─ has_victim → Victim
  ├─ has_phone → Phone
  ├─ is_type → ScamType（刷单返利/杀猪盘/冒充公检法等）
  ├─ in_city → City
  ├─ involves_account → Account（收款账户，含银行卡号/开户行）
  ├─ involves_perpetrator → Perpetrator（违法者，含姓名/身份证号/角色）
  └─ similar → Case（话术相似边，BGE cos ≥ 0.5）

Account（收款账户）
  ├─ share_account → Account（共享账户关联边）
  └─ fund_flow → Account（资金流转有向边，含金额+时间+交易类型）

Gang（团伙）
  ├─ members → Case[]
  ├─ confidence → Float
  ├─ gate_decision → String（建议冻结/待人工复核）
  └─ freeze_candidates → Account[]

OperationLog（操作审计—append only）
FreezeDecision（冻卡决策审计—append only）
```
