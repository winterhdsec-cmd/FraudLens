# 申报书排版原则（本项目专属）

1. 行间距：正文内容设置为固定值 22 磅
2. 例外情况：
   - 表格**内部**的所有内容不设置行间距 22，保持原有紧凑排版以避免表格溢出
   - 第一页（封面）的个人信息（从项目负责人到指导教师信息表格）不设置行间距 22，保持原排版
3. 结构要求：
   - 不允许页面有大片空白，每一页尽量填满
   - 图题放在图下方，表题放在表上方，解释段紧跟图/表
   - 避免 1×1 表格嵌套二级标题，消除嵌套表格现象
   - 一级标题"一、"，二级"（一）"，三级"1."，列举"（1）"，编号体系全文统一
4. 其他约束：
   - 正文（含附录论文正文、图题）统一为小四（12pt），不得混用五号（10.5pt）；表格内部与参考文献注释不在此限
   - 申报书中不得包含专利相关内容（尚未申请专利）
   - 申报书中不得包含论文全文，论文全文作为独立附件提交
   - 附录仅放佐证材料清单，不放大段正文
   - 行文避免出现"供评委参考"等解释性语言
   - 全文尽量使用大白话解释术语，避免过度技术化和参数堆叠
