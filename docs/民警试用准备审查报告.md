## 一、涉密合规(最高优先级,不解决不能上真实公安网)

### 🔴 严重:云 LLM 默认打开,且数据涉密

- `docker-compose.yml:85` 写了 `DISABLE_CLOUD_LLM: ${DISABLE_CLOUD_LLM:-0}` —— **默认 0 = 云端 LLM 默认启用**,配置里有 `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL`。
- 公安办案数据(受害人电话、账户、资金)属敏感公民个人信息。**任何外呼 LLM 都触碰数据出境红线**。
- **改法**:公安内网环境必须 `DISABLE_CLOUD_LLM=1`(走纯本地规则/规则兜底),顶层 `.env` 强制覆盖,README 标注"涉密数据严禁云端推理"。你的 BGE/HAN 是本地的不受影响,但 LLM 会商环节如果是云端就违规。

### 🔴 严重:一堆硬编码弱口令/默认密钥,直接进公安网等于裸奔

| 位置 | 现状 | 风险 |
|---|---|---|
| `docker-compose.yml` 全局 | `DB_PASSWORD:-20051223`、`REDIS_PASSWORD:-20051223`、`MINIO_PASSWORD:fraudlens123` | 弱口令,公安网内横向即可入侵 |
| `nginx/JWT` | 默认 `JWT_SECRET_KEY=fraudlens-jwt-secret-key-2024` | JWT 密钥可被直接猜出,伪造管理员 token |
| `run-local.bat` | 默认账号 `admin / admin123` | 首发弱口令 |
| `TLS_ENABLED=0` | 默认不启用 HTTPS | 政务/实地演示裸 HTTP 不安全 |

**给民警试用前必须**:换随机强密码、JWT 密钥、开启 TLS、admin 强制改密。这些是"上线"必修,不是可选项。

### 🟡 中:公安系统上线需等保定级/立项审批

- 真实民警在工作机上装你的系统,大概率需要**单位信息化审批 + 安全评估(等保二级起步)+ 数据保密协议**。这是现实流程,不是你能用代码绕过的。
- **建议**:现阶段定位为"**试点演示 + 民警反馈收集**"(用脱敏 demo 数据),而非"正式办案系统"。比赛材料里把这一点写成"落地路径的合规考量",评委认可度会更高。

## 二、可信度(民警最在意的:凭什么信你的"团伙"结论)

这是纯技术/产品问题,可以补,且是比赛加分项(呼应你已有的诚实实验观)。

### 🔴 要命的:串并案"并对了"与"并错了"的代价不对等

- 反诈串并案是**办案依据**,串错可能引发程序问题(错抓、办错案)。你现有输出是"团伙及其成员",但民警需要的是:**为什么并这个案 → 可解释的证据链**。
- 前端有 `GroupsView`(团伙画像),后端有 `gangs.py`;要核验:**每个团伙是否展示"依据哪张共享卡/哪条话术相似、相似度是多少"**。如果只有结论没有依据,民警不敢用、也不能用。

### 🟡 中:缺「人工核准/否决」闭环的确认

- 你有 `reviews.py`、`workflow.py` 路由,但需要确认是否形成"**系统判定 → 民警核准/否决 → 写入留痕 → 追回或纠正**"的完整闭环。判别系统必须"人审兜底",这既是公安实务要求,也是贵项目"拒判门控/敢说拿不准"理念的自然延伸——**把"转人工"做成显性功能**。

### 🟡 中:置信度与阈值要透明

- 你的 25% 巨簇门控、锚点充足阈值、增量"宁缺毋滥"都是很好的理念;但要在界面上向民警**说清每一档输出的置信依据和当它"拿不准"时的回退行为**,不要只给一个干巴巴的名单。

## 三、可用性(民警真实工作节奏下的体验)

### 🟡 中:性能基准缺失

- BGE-large + HAN 全 CPU 跑,**单案分析多久?几十上百案全量聚类多久?** 民警办案是快节奏,等待 30s 以上就会弃用。
- 你的实验(200 案 L1)<u>恰好是全方法失效的边界</u>——民警真实案件量级很可能超过你的测试规模。增量匹配已缓解,但需要一份**面向真实规模(如 500/1000 案)的性能-精度对照**,证明"接入你的系统后天天能用"。

### 🟢 低:演示数据真实性

- 现在全部是模拟数据。民警试用的**第一反应是数据像不像真的**。建议准备一套<u>脱敏但真实结构</u>的样本(话术模板、账户层级、资金流向像真案),别让民警第一眼看到"一眼假的数据"就失去兴趣。

## 四、可运维与交付物(民警试用不是只给你点一下)

要给民警试用,你得交付的不只是代码,还有:

| 交付物 | 说明 | 状态 |
|---|---|---|
| **部署手册** | 公安内网/离线环境如何装(无外网拉 docker 镜像、无外网 LLM) | ❌ 缺 |

| **脱敏测试集** | 结构真实的演示数据 | ⚠️ 模拟,需真实化 |
| **反馈收集表** | 民警试用后:哪些看不懂/哪些好用/哪些不敢信 | ❌ 缺 |
| **数据保密协议** | 脱敏数据使用范围、不外传承诺 | ❌ 缺 |
