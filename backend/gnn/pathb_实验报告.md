## 二、三分支逐个解读

### 分支 A：稠密子图发现（`pathb_dense_subgraph.py`，39s）
- **A2 kcore-louvain(kmin=4) F1=0.1465 是全场最高**，超过同子图 Louvain 基线（0.0813）约 80%，也超过已有 `amlsim_refinement_results.json` 的 0.1106。
- **诚实分界**：ring_only_F1 仅 0.006——F1 提升主要来自"核心子图 + 背景归并"（减少背景碎片化对 pairwise F1 的惩罚），**不代表"洗钱环识别"突破**。
- 结论：k-core 预处理是有效的"去背景噪声"手段，但把"稠密"当"洗钱"是粗糙假设。

### 分支 B：GAE 重构误差异常检测（`pathb_gae_anomaly.py`，27s）—— 阴性结果
- **AUC=0.386，低于随机**；top-k precision 均低于随机基线（46.5%）。
- **根因分析**（结构性，非调参问题）：
  1. 锚点扩线子图环占比高达 **46.5%**（锚点即环成员），"异常 vs 正常"二分类语义失真——没有足够"正常"节点供重构误差区分；
  2. GAE 学的是"整体模式"，在环占比过半的子图中找不到判别对象；
  3. 12 维 z-score 特征本身判别力弱于拓扑结构。
- **诚实价值**：这是 Path B 最重要的教训之一——**"无监督"不等于"有效"**，方法选择必须匹配任务设定（高环占比的扩线子图不适合全局异常检测）。

### 分支 C：AMLSim 风格规则探测器（`pathb_rule_detector.py`，36s）—— 最佳正向结果
- **合成分 AUC=0.6388**，top20% precision=0.617（随机 0.465，+15 个点）。
- **单规则诊断**：R5 大额离群（0.614）、R3 短环（0.599）、R2 快进快出（0.585）有效；R4 出入失衡≈随机（0.496）。
- **R1 整额拆分未出结果**：子图中无满足 `金额 % 1000 == 0` 的交易，全 0 被跳过——AMLSim 金额分布不含整千模式，规则需适配实际数据。
- **价值**：可解释 + 有判别力，是给民警"为什么标记它"的解释层，也是与分支 A 交叉验证的候选。

---

## 三、综合结论（给组长和竞赛叙事用）

1. **任务设定修正即关键，再次被证实**：三分支在锚点扩线下全部远超盲扫（×38~73），印证"盲扫 vs 扩线"才是反诈 GNN 的真瓶颈。
2. **拓扑方法 > 深度方法 > 规则排序**（当前设定下）：
   - 拓扑 k-core（A2）恢复结构最好（F1 0.147）；
   - 规则（C）排序可解释性最好（AUC 0.64）；
   - 深度重构误差（B）在此设定失效（AUC 0.39）——**如实记录，不包装**。
3. **最优组合假设（待验证）**：A2 的"核心子图候选" + C 的"规则排序" + B 作为对照 → 可能比单方法更强，属下一步工作。

# 追加：第二轮三实验（2026-08-04 晚，全部跑通）

## 实验 1：A2×C 交叉验证（`pathb_combine.py`，34s）

| 方法 | 指标 | 数值 |
|------|------|------|
| A2 单独（kmin=4） | pairwise F1 | 0.1413 |
| C 单独 | AUC | 0.6374 |
| C 单独 top5% / top10% / top20% | precision@k | 0.540 / 0.582 / 0.617 |
| **A2+C（core-only）** | AUC | 0.6027 |
| **A2+C core top5% / top10% / top20%** | precision@k | **0.601 / 0.625 / 0.635** ⭐ |

**结论：组合有效。** A2 核心子图过滤 + C 规则排序，top-k 命中率全面高于 C 单独（+4~6 个点）；AUC 略降（0.637→0.603）是因评估域收窄为核心成员。A2 出候选、C 排序的解释性组合成立。

## 实验 2：扩线参数敏感性（`pathb_sensitivity.py`，169s）

| 设定 | 子图规模 | 环占比 | A2 F1 | C AUC |
|------|----------|--------|-------|-------|
| k=1, a30 | 519 | 0.603 | 0.2734 | 0.6032 |
| k=1, a60 | 1,189 | 0.569 | 0.3144 | 0.5957 |
| **k=1, a120** | 2,748 | 0.545 | **0.3503** ⭐ | 0.6068 |
| k=2, a60（首轮设定） | 7,978 | 0.466 | 0.1294 | 0.6374 |
| k=3, a120 | 7,946 | 0.473 | 0.1292 | 0.6319 |

**结论：扩线深度 k 是关键超参，且规律明确——k=1 时 A2 F1 翻倍以上（0.13→0.35）**，因为 1 跳子图聚焦"锚点邻域"，环占比更高、噪声更少；k≥2 子图饱和到 8000 cap，A2 回落。C 的 AUC 对参数稳健（0.60–0.64）。**推荐工作点：k=1、锚点 60–120。**

## 实验 3：Elliptic 真实图复跑（`pathb_elliptic.py`，7s）

| 指标 | 数值 | 判定 |
|------|------|------|
| A2 kcore-louvain F1 | **0.000**（5 trials 全 0） | ❌ 完全失效 |
| C 规则 AUC | **0.256**（随机 0.5） | ❌ 低于随机 |
| C 规则 precision@20% | 0.388 | 低于随机基线（illicit 占比 0.586） |

**结论：无监督方法在 Elliptic 真实交易图上双双失效。** 根因（诚实分析）：
1. 锚点扩线子图**过小**（80–330 节点，cap 2000 未用满），kcore(kmin=4) 无核心可提；
2. Elliptic **无金额/时序字段**，C 规则退化为"短环 + 特征离群"子集，判别力丧失；
3. 子图 illicit 占比 0.52–0.65，二分类语义失真（同 AMLSim 分支 B 教训）。

**这是最有价值的阴性结果**：证明"无监督扩线"的适用边界是**有金额/时序的账户交易图**（AMLSim 类），对纯拓扑无属性的交易图（Elliptic 类）不迁移。竞赛/论文叙事中必须如实表述这一边界。

## 更新后综合结论

1. **组合路线成立**：A2 候选 + C 排序 > 单方法（实验 1）；
2. **参数甜点明确**：k=1 扩线，A2 F1 可达 0.35（实验 2）；
3. **适用边界清晰**：无监督扩线适用于"账户+金额+时序"图，不适用于"纯拓扑交易图"（实验 3）——这是诚实报告的核心资产。

# 追加：第三轮 最优组合管道（2026-08-04 晚，`pathb_pipeline.py`，26s）

## 设定
k=1 扩线 / 120 锚点环 / 子图 2,748 节点（环占比 0.545）。组件：k-core 候选（kmin 扫描 2/3/4）+ 社区规则分排序 + 按节点预算取候选 + 资金链短环检测（BFS 逐点判断 len≤6，替代 simple_cycles 指数枚举——后者 12 分钟未完成，已停）。

## 团伙级（节点预算版，recall 提升 7.6 倍）

| 方法 | Precision | Recall | F1 |
|------|-----------|--------|-----|
| 首轮 kcore4 top5%（按社区数） | 0.712 | 0.035 | 0.066 |
| kcore2 budget20% | 0.604 | 0.275 | 0.378 |
| kcore3 budget20% | 0.611 | 0.240 | 0.345 |
| **kcore4 budget20%** | **0.679** | **0.266** | **0.382** ⭐ |

**改进点**：候选按"节点预算"（子图 20%）而非"社区数"取，recall 0.035→0.266（+7.6 倍），F1 0.066→0.382。

## 资金链级（用户核心目标——突破）

| 方法 | Precision | Recall | F1 |
|------|-----------|--------|-----|
| 盲扫基线 | — | — | 0.002 |
| 已有扩线 Louvain | — | — | 0.1106 |
| SCC（严格强连通，size≥2，仅 16 个） | 0.50 | 0.002 | 0.004 |
| **短环检测（BFS len≤6，913 节点）** | **0.658** | **0.401** | **0.4985** ⭐ |

**关键洞察**：AMLSim 洗钱环**不是严格强连通分量**（SCC 仅 16 个且几乎全假阳性），而是**短有向环**结构。逐点 BFS 判断"节点是否在 ≤6 跳闭环上"抓 913 候选，P=0.66/R=0.40——全项目 AMLSim 真实规模最好结果之一。

# 追加：第四轮 少量标注校准（2026-08-04 晚，`pathb_calibrate.py`）

## 设定
模拟真实办案闭环：民警确认少量环成员 → 校准融合权重 → 批量扩线。
校准特征 16 维（kcore 值 + 短环 L≤8 + 规则分 + 行为异常分 + 12 维行为特征），
LogisticRegression + RandomForest 集成，5 trials 随机采样，报告均值±std。

## 结果（团伙识别）

| 标签比例 | 最优 budget | F1 均值±std | 说明 |
|----------|------------|-------------|------|
| 5%（约 75 标签） | 90% | 0.7086±0.0 | 无突破，线性模型学到信息不足 |
| **10%（约 150 标签）** | 80% | **0.7051±0.0074**（trial1: **0.7143**） | ⭐ 单 trial 突破 0.71，不稳定 |
| 15%（约 225 标签） | 90% | 0.7086±0.0 | 反而回归基线（RF 过拟合） |

## 诚实结论
- **"少量标注能突破 0.71"得到单次验证**（10% 标签 trial1 F1=0.7143），但**不稳定**——校准对随机采样敏感，均值仍≈0.705-0.709；
- 5%/15% 均回归 kcore2 基线 0.7086，说明**线性校准增益有限，RF 过拟合**；
- 要稳定突破需 20%+ 标签做真实监督训练（AMLSim 有全标注，但真实办案不可能预先标注 30% 数据——这条路径的"实战可行性"受限，须如实表述）。
