## 1. 三个无监督分支（按投入产出排序）

### 分支 A：稠密子图发现（2–3 天）★ 先做
- **做法**：k-core 分解（networkx 内置）+ 社区密度/资金回流比打分，对每个社区输出可疑度排序。
- **复用**：`community.py` 的 `_louvain_detection` 出社区 → 对每个社区算密度（边/节点比）、环占比 → 打分。
- **为什么先做**：Louvain 在扩线设定已有 0.11 的实测基线，稠密子图是对它的直接增强，2 天出第一个"无监督真实数字"，快速验证评测管线通不通。
- **诚实预期**：不预设能超过 0.11；出什么报什么。

### 分支 B：GAE 重构误差异常检测（DOMINANT 化）（4–6 天）★ 核心贡献
- **做法**：改造 `deep_clustering.py` 的 `GraphAutoEncoder`——训练时同时重建邻接矩阵 + 节点特征，**异常分数 = 重构误差**（重建得越差 ≈ 越偏离正常模式 ≈ 越可疑），无需任何标签。
- **改动点**：GAE 的 loss 增加邻接重建项（当前只有特征重建）；新增 `anomaly_score(x, adj)` 方法；输出 top-k 可疑账户。
- **为什么是它**：这是图异常检测的标准无监督范式（DOMINANT 即此思路），在域偏移下依然可用——模型学的是"正常账户长什么样"，不是"洗钱长什么样"。
- **诚实预期**：重构误差 ≠ 洗钱判定，是**可疑度排序线索**；必须和分支 C 规则交叉验证。

### 分支 C：规则探测器（AMLSim 风格）（2–3 天）★ 可解释性
- **做法**：实现 AMLSim 论文的硬规则打分——多账户共享设备/手机号、多币种快速换转、整额拆分入金、资金快进快出（出入账时间窗 < 阈值）等。
- **复用**：`account_temporal.py` 的 12 维行为特征直接承载这些规则。
- **为什么要有它**：民警最信任的是"规则可解释"，规则探测器是给民警的"为什么标记它"的解释层；同时是分支 B 的交叉验证器。
- **诚实预期**：规则能抓到"模式明显"的环，抓不到隐蔽环——这本身是边界认知素材。

## 2. 统一评测协议（诚实红线，不可妥协）

- **数据集**：AMLSim canonical（43,614 账户 / 1,305 环）+ Elliptic（真实图对照）。
- **设定**：锚点扩线——60 锚点、k=2、子图约 8,000 节点（复用 `experiment_elliptic_refine.py` 的协议）。
- **指标**：F1 + ring_only_F1 + precision/recall；**必须与盲扫基线（0.002）和扩线 Louvain（0.11）同表对比**。
- **报告格式**：每个方法一行，标注"无监督/无标签"；**任何结果不写"真实数据验证通过"**，只写"锚点设定下的无监督可恢复性"。
- **产出**：`backend/gnn/pathb_results.json` + `pathb_实验报告.md`，数字进竞赛计划书前须经本中枢复核。
