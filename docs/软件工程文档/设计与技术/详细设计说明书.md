## 1. Orchestrator 编排器详细设计

**文件**: `backend/agents/orchestrator.py`

### 状态定义

```python
class OrchestratorState(TypedDict):
    session_id: str
    case_data: dict           # 案件原始数据
    plan: dict                # 执行计划
    preprocess_result: dict   # 预处理结果（实体/资金流）
    analysis_result: dict     # 分析结果
    cluster_result: dict      # 聚类结果（团伙列表）
    reflection: dict          # 反思评估
    retry_count: int          # 重试次数
    checkpoints: list         # 检查点列表
```

### 节点实现

| 节点 | 入口函数 | 核心逻辑 |
|------|----------|----------|
| plan | `plan_node(state)` | 解析用户意图 → 确定分析类型（单案/多案）→ 提取关键要素 |
| preprocess | `preprocess_node(state)` | 调用 AnalystAgent 抽取实体 → 解析资金流水适配器 → 准备图构建参数 |
| analyze | `analyze_node(state)` | AnalystAgent.run(): 提取证据 → 检索相似案件(BGE) → 风险评估 → LLM 报告 |
| cluster | `cluster_node(state)` | ClusterAgent.run(): graph_builder.build() → HAN.encode() → 聚类 → gang_detector.detect() |
| reflect | `reflect_node(state)` | 计算 quality_score → 生成调整策略 → 更新 retry_count |

### 条件边

```python
workflow.add_conditional_edges(
    "reflect",
    should_retry,    # 决策函数
    {
        True: "analyze",    # 回连重算
        False: END          # 结束
    }
)

def should_retry(state):
    q = state["reflection"]["quality_score"]
    n = state["retry_count"]
    return q < 0.6 and n < state.get("max_iter", 3)
```

```python
    def __init__(self, in_dim, out_dim):

        self.W = nn.Linear(in_dim, out_dim)                     # 变换矩阵
        self.leaky_relu = nn.LeakyReLU(0.2)

    def forward(self, x, edge_index):
        # 1. 线性变换: h' = W·h
        # 2. 注意力系数: α_uv = softmax(LeakyReLU(a·[W·h_u || W·h_v]))
        # 3. 加权聚合: h_u^Φ = Σ α_uv · W·h_v
```

## 3. GraphBuilder 异构图构建器详细设计

**文件**: `backend/gnn/graph_builder.py`

### 3.1 节点构建

```python
def build(self, cases, accounts_tx=None):
    G = nx.Graph()  # 主图无向（零改动 HAN/社区接口）
    # -- 案件节点 --
    for case in cases:
        G.add_node(f"case_{case.id}", type="case",
                   features=extract_features(case))  # 金额/受害者数/话术长度等统计特征
    # -- 账户节点 --
    for acc in accounts:
        G.add_node(f"account_{acc.id}", type="account",
                   features=extract_account_features(acc))  # 交易次数/金额/对手数
    # -- 违法者节点 --
    for perp in perpetrators:
        G.add_node(f"perp_{perp.id}", type="perpetrator",
                   features=extract_perp_features(perp))
```

## 4. GangDetector 团伙检测器详细设计

**文件**: `backend/gnn/gang_detector.py`

### 4.1 检测流程

```python
class GangDetector:
    def detect(self, case_embeddings, graph, accounts_tx=None):
        # Step 1: 聚类
        labels = self.cluster(case_embeddings)

        # Step 2: 每个簇 → 团伙
        gangs = []
        for cluster_id in np.unique(labels):
            gang_cases = [cases[i] for i in np.where(labels==cluster_id)[0]]
            gang = self._generate_gang_info(gang_cases, graph, accounts_tx)
            gangs.append(gang)

        # Step 3: 置信度门控
        for gang in gangs:
            gang["confidence"] = self._calc_confidence(gang)
            gang["gate_decision"] = "建议冻结" if gang["confidence"] >= 0.5 else "待人工复核"

        return gangs
```

### 4.2 置信度计算

```python
def _calc_confidence(gang):
    scale_norm  = min(gang["n_cases"] / 10, 1.0)        # 案件数归一化
    amount_norm = min(log1p(gang["total_amount"]) / 15, 1.0)  # 金额归一化
    acc_norm    = min(gang["n_accounts"] / 20, 1.0)      # 账户数归一化
    reflux_flag = 1.0 if gang["has_reflux_cycle"] else 0.0

    return 0.30*scale_norm + 0.20*amount_norm + 0.20*acc_norm + 0.30*reflux_flag
```

### 4.3 资金回流闭环检测

```python
def detect_reflux_cycles(accounts_tx):
    G = nx.DiGraph()
    for tx in accounts_tx:
        G.add_edge(tx.from_account, tx.to_account, amount=tx.amount)
    cycles = list(nx.simple_cycles(G))  # 找有向环
    return [cycle for cycle in cycles if len(cycle) >= 3]  # 至少 3 跳
```
