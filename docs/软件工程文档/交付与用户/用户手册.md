# FraudLens 用户手册

> **文档编号**: USER-MANUAL-001 | **版本**: v1.0 | **日期**: 2026-08-04  
> **适用角色**: 研判员（police）、审批人（admin）

---

## 1. 系统简介

FraudLens 是面向反诈民警的**智能辅助研判系统**。你只需要上传诈骗线索（报案笔录、聊天截图、资金流水），系统会自动帮您：

- 提取关键实体（嫌疑人/受害者的姓名、手机号、银行卡号）
- 画出涉案人员和账户之间的**关系网络图**
- 用 AI 发现隐藏的**犯罪团伙**（哪些案子可能是同一伙人干的）
- 发现**洗钱闭环**（钱转了一圈又回来的路径）
- 给出**冻卡建议**，并附上客观的**可信度评分**

**重点**：系统给出的所有"冻卡建议"都需要您人工审批，系统不会自动执行任何操作。

1. 打开浏览器访问系统地址（例如 `http://localhost`）
2. 输入您的用户名和密码
3. 首次使用请联系管理员创建账号

```
默认账号: admin / admin123（请立即修改密码）
```

## 3. 上传案件线索

### 方式一：手动录入

1. 点击左侧菜单 **「案件录入」**
2. 填写基本信息：
   - **案件标题**：简要描述（如"2026年3月冒充公检法诈骗案"）
   - **诈骗类型**：刷单返利 / 杀猪盘 / 冒充公检法 / 贷款诈骗 / 其他
   - **案情描述**：简要描述案件经过
   - **涉案金额**：受害人总损失金额
   - **话术文本**：粘贴诈骗分子的聊天记录、短信内容
3. 点击 **「提交」**

### 方式二：上传文件

1. 点击左侧菜单 **「材料上传」**
2. 拖拽或选择文件上传，支持：
   - **图片**：聊天截图、转账截图（系统自动 OCR 识别）
   - **PDF**：报案笔录扫描件
   - **DOCX**：Word 格式案件文档
   - **CSV/Excel**：银行资金流水
3. 系统自动解析后，检查识别结果是否准确，如有误可手动修改
4. 点击 **「确认并提交研判」**

---

## 4. 智能研判

### 4.1 发起研判

提交案件材料后，系统自动进入研判流程：

```
案件提交 → 预处理（实体抽取）→ 分析（证据提取/风险评估）
→ 聚类（团伙发现）→ 反思（质量检查，必要时重算）
→ 生成报告
```

研判过程需要 30-60 秒（复杂案件可能更久），右侧会显示实时进度。

### 4.2 查看研判结果

研判完成后，您会看到：

| 板块 | 内容 |
|------|------|
| **团伙概览** | 系统发现了几个团伙、每个团伙包含多少案件 |
| **关系网络图** | 红色=团伙节点、蓝色=案件、绿色=账户、可拖拽缩放 |
| **资金流向图** | 账户之间的资金流转路线，闭环高亮显示 |
| **冻卡建议** | 建议冻结的账户列表 + 每个账户的可信度评分 |
| **研判报告** | 完整的分析报告（可下载/打印） |

---

## 5. 解读研判结果

### 5.1 看懂团伙关系图

- **红色圆点**：犯罪团伙
- **蓝色方块**：案件
- **绿色三角**：收款账户
- **黄色菱形**：违法者
- **连线**：节点之间的关联（共享账户/同一违法者/资金流转）
- **虚线**：话术相似（两案用了类似的诈骗话术）

### 5.2 看懂可信度评分

每个冻卡建议附有置信度评分：

| 评分 | 含义 | 建议操作 |
|------|------|----------|
| **≥ 0.7**（绿色） | 高可信 | 强烈建议考虑冻结 |
| **0.5-0.7**（橙色） | 中等可信 | 建议冻结，建议结合其他线索 |
| **< 0.5**（红色） | 低可信 | **建议人工复核后再决定，不推荐直接冻结** |

评分由四个因素加权计算：
- 团伙案件数
- 涉案总金额
- 关联账户数
- 是否检出资金回流闭环（一个关键信号）

### 5.3 看懂资金回流闭环

系统自动检测"钱转了一圈又回来"的路径，这是洗钱的重要特征：

```
例: 账户A → 账户B → 账户C → 账户D → 回到账户A
```

检出回流闭环的案件在报告中会**高亮标记**，是该团伙为洗钱团伙的重要证据。

## 6. 人工复核

当系统给出"待人工复核"的建议时，您可以：

1. 点击 **「复核工作台」**
2. 查看系统给出的低置信案件/团伙详情
3. 操作：
   - **确认并案**：将系统未关联的案件手动加入团伙
   - **拆分团伙**：将系统误判的关联拆开
   - **修正诈骗类型**：修改系统识别的类型
   - **补充实体**：添加系统未识别的嫌疑人/账户
   - **标注误报**：标记系统误判为正常交易
4. 提交后，系统会根据您的复核意见重新分析

## 7. AI 对话助手

点击左侧 **「AI 助手」**，可以用自然语言查询：

```
- "最近的刷单诈骗案件有什么特点？"
- "冒充公检法诈骗的典型话术有哪些？"
- "武汉市本月诈骗案件统计"
- "诈骗金额超过10万的案件有哪些？"
```

助手基于系统内置的反诈知识库回答，信息来源包括：
- 公安反诈法规
- 典型诈骗案例
- 诈骗手法分析

## 9. 报告导出

研判完成后，可以导出报告：

1. 在案件详情页或团伙详情页点击 **「导出报告」**
2. 选择格式：**DOCX**（Word 文档，可编辑）或 **PDF**
3. 报告包含：案件信息、团伙分析、关系网络图、冻卡建议及依据、可信度评分

---

## 10. 注意事项

⚠️ **重要提醒**

1. **系统给出的是"建议"，不是"决定"**：所有冻卡、并案等操作均需人工审批后方可执行
2. **低可信度结果务必复核**：系统在数据不充分时会主动标注为"待复核"，请勿直接采纳
3. **数据不出域**：所有案件数据存储在本地服务器，不上传外部（除您主动开启的云端 AI 分析功能）
4. **审计可追溯**：所有操作均记录在案，包括谁在什么时候查看了哪个案件、做了什么决策
5. **系统有失败可能**：在数据稀疏或案情复杂时系统可能无法发现所有团伙，请结合您的办案经验综合判断
