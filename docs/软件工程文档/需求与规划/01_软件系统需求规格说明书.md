## 一、项目身份与定位

| 维度 | 内容 |
|------|------|
| **名称** | FraudLens — 多智能体编排 + 图神经网络的反诈团伙智能研判系统 |
| **定位** | 面向公安反诈中心 / 基层派出所的智能辅助研判系统，单机 / 内网部署 |
| **负责人** | 韩冬（湖北警官学院 信息技术系 大二） |
| **核心技术标签** | LangGraph 多智能体反思闭环 + HAN 异构图注意力网络 + 资金链回流闭环 + 客观置信度门控 |
| **目标用户** | 一线反诈民警（研判员、审批人、审计员） |
| **部署形态** | Docker Compose 全栈（单机）→ 目标 K8s（多副本）；默认内网部署，云端 LLM 可关闭 |
| **成熟度** | B+ 科研原型级（工程综合评分）；**不可对外宣称"生产部署"** |

| DeepSeek API | 云端 LLM（可降级旁路，默认关闭） | ✅ |

### 核心数据实体

```
Case（案件）
  ├─ has_victim → Victim（受害者）
  ├─ has_phone → Phone（手机号）
  ├─ is_type → ScamType（诈骗类型）
  ├─ in_city → City（城市）
  ├─ involves_account → Account（收款账户）
  ├─ involves_perpetrator → Perpetrator（违法者）
  └─ similar → Case（话术相似边，BGE cos≥0.5）

Account（收款账户）
  ├─ share_account → Account（共享账户关联）
  └─ fund_flow → Account（资金流转有向边，含金额+时间）

OperationLog（操作审计）
FreezeDecision（冻卡决策审计）
Gang（团伙）
Report（研判报告）
```

### 数据不出域设计

- 关系数据全程本地 MySQL，不传输至外部服务
- BGE 嵌入模型本地推理（`bge-large-zh-v1.5/` 目录）
- 云端 DeepSeek 默认关闭（`DISABLE_CLOUD_LLM=1`），启用时强制脱敏（`CLOUD_LLM_MASK=1`）
- 图与向量为可重建派生视图，不持久化为独立真值

## 十、诚实红线（最高优先级）

1. **合成 ≠ 真实验证**：绝不把合成 HAN F1=0.947 说成真实数据验证
2. **真实数据结论**：AMLSim 43,614 账户全图 F1≈0.002–0.010（所有方法失效）；Elliptic 盲扫全败（F1≈0.016）；Elliptic 节点级评测进一步量化——无监督冷启动 AUC 0.14–0.40（≤随机），**有监督域内训练 AUC=0.891**（时序划分，见 `elliptic_supervised.py`）。结论：系统缺的是标注而非算法，无监督失效是诚实边界而非能力否定
3. **GNN 非全设定占优**：在结构清晰子图上未显著优于 Louvain；增量在拓扑受扰时方显
4. **当前定位**：B+ 科研原型级；对外表述"扎实科研原型"，**不可称"已生产部署"**
5. **所有数字须可追溯到实验脚本**，未实跑标注"待补"，不得编造
