## 2. 通用规范

### 2.1 认证方式

```
Authorization: Bearer {access_token}
Token 签发: JWT HS256, 24h 有效期
刷新令牌: 7d 有效期, Redis 黑名单
```

### 2.2 通用响应格式

```json
// 成功
{ "code": 200, "data": {...}, "message": "ok" }

// 错误
{ "code": 4xx/5xx, "data": null, "message": "错误描述" }
```

### 2.3 通用错误码

| 状态码 | 含义 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误（Pydantic 校验失败） |
| 401 | 未认证 / Token 过期 |
| 403 | 无权限（角色不足/跨部门） |
| 404 | 资源不存在 |
| 429 | 请求频率超限 |
| 500 | 服务器内部错误（含降级信息） |

```
{

```

```
请求参数: ?user_id=1&action=freeze&from=2026-07-01&to=2026-08-01&page=1
```

## 5. 健康检查接口

### GET /health

```
响应: 200 { "status": "healthy" }
用途: 存活检查（仅验证进程存活）
```

### GET /ready

```
响应:
200 { "status": "ready", "checks": { "mysql": "ok", "redis": "ok", "gnn_model": "loaded" } }
503 { "status": "not_ready", "checks": { "mysql": "error: connection refused" } }
用途: 就绪检查（验证所有依赖可用）
```
