FraudLens 反诈研判系统 · 项目地图

写给「非作者」的快速上手 — 重点看「真做了什么 / 哪里是占位 / 从哪入手」

一、一句话定位

面向公安反诈中心的 多智能体 + 图神经网络 研判系统：帮警察从海量交易/通信数据中自动发现诈骗团伙、串并案件、可视化资金链。单机/内网部署，不做云端商业化。

技术栈：前端 Vue3 + Element Plus + ECharts + vis-network ；后端 FastAPI + LangGraph 真反思闭环；数据层 MySQL + Redis + BGE 本地嵌入 + DeepSeek 云端 + GNN。

二、整体架构（三层）

① 前端（你看得见的部分）

Vue3 + Vite + Element Plus
ECharts 图表 / vis-network 关系图
axios + JWT + socket.io 实时进度
前端入口：frontend/src/router/index.js（19 个页面）

② 后端（AI 大脑）

FastAPI（端口 5003）
入口：backend/main.py

GNN：backend/gnn/
13 个路由：auth/cases/gangs/sessions/alerts/dashboard…

③ 数据 & 部署

MySQL 8（案件/团伙数据）
Redis（缓存/队列）
Docker 全套：docker-compose.yml
含 mysql/redis/minio/nginx/prometheus/grafana

三、后端最核心：LangGraph 反思闭环（真闭环，不是摆设）

文件 backend/agents/orchestrator.py 用一个有向图把 5 个阶段串起来，最后一步「反思」会判断质量，不够好就回到「分析」重做 —— 这就是所谓的真反思。

规划→ 预处理→ 分析→ 聚类→ 反思 ↺ 条件回连 →分析（重做） ／ 达标 → END
  • 真回连：add_conditional_edges("reflect_node", ...{"continue":"analyze_node", END:END})
  • 真调参：_adjust_strategy 会关闭 GNN / 调小聚类粒度，不只是打日志
  • 最多迭代 2 轮（MAX_REFLECT_ITER），避免死循环

四、GNN 两条线（都是真实现）

Track A · 资金链 GraphSAGE
文件：backend/gnn/gnn_model.py + gang_detector.py
环子图检测 F1：训练后 0.086 → 0.866（约 ×10）
Track B · 案情异构 HAN
文件：backend/gnn/han_model.py（语义注意力）
合成数据下 F1=0.955；真实数据暂未见显著增益
诚实边界（很重要）：在真实 AMLSim 数据集上，所有方法 F1 仅 0.002–0.010，「GNN 碾压」只在合成/环子图场景成立。写论文时不要说「GNN 大幅提升真实数据效果」，那会穿帮。

六、给你的学习路线（大二 / 非作者）

  1. 先懂数据流：读 frontend/src/api.js → 看他点了什么按钮、调了哪个后端接口。
  2. 再懂大脑：读 backend/agents/orchestrator.py 的 5 阶段，这是系统的「骨架」。
  3. 看 AI 怎么干活：读 backend/agents/specialist_agents.py，九个 Agent 各管一摊（抽取/资金流/通信流/矛盾/CaseRAG/聚类/画像/报告/对话助教）。
  4. 看 AI 怎么「想」：读 backend/gnn/，理解 GNN 为什么能找团伙。
  5. 别碰：freeze_executor.py（占位）、pathb_*/experiment_*（实验残留）、probes（探针）。
一句话心智模型：用户在前端点几下 → 后端用「规划→分析→聚类→反思」循环跑 AI → 用 GNN 挖团伙 → 前端把结果画成图。你就沿着这条线读，不会被 1 万多文件吓到。
